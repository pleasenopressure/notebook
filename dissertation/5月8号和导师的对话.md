I revised the project plan based on our last meeting. The main framing is that this is not just a robot chatbot project, but a design-and-evaluation project for a robotic facilitator that supports human-human conversation.

I reflected three main points from our discussion. First, the robot should be a light-touch facilitator rather than a third dominant speaker. Second, the work should be split into two stages: first stabilise the technical framework, then run the user evaluation. Third, the evaluation should focus on whether the robot changes the conversation, so I planned a comparison between conversation without the robot and conversation with the robotic facilitator.

The technical plan starts from a local simulation, where two users type messages and the system decides whether the robot should intervene. Then I can move to the physical robot if feasible. The evaluation will use objective measures like conversation duration, silence, speaking turns and robot interventions, plus questionnaire ratings like comfort, naturalness, helpfulness and intrusiveness.

I also included fallbacks, so if speech recognition, visual input or APIs are difficult, I can fall back to typed input or speech-only facilitation.
