## 📌 课程精炼摘要 (速读版)

本节课探讨了一个全新的方向：**使用自编码器（Autoencoder）进行异常检测（Anomaly Detection）**，并将其应用于极度不平衡的信用卡欺诈数据集 。不同于传统的分类模型输出概率，自编码器解决的是回归问题，通过学习“正常数据”的模式并尝试重建输入，以此来计算重建误差 。当模型遇到未见过的“欺诈数据”时，重建误差会显著增大，我们便可以通过设定阈值（如 Z-score > 3）来识别异常 。

## 📖 详细知识点梳理 (结合课件与课堂实录)

#### 1. 数据预处理与极度不平衡问题 (07:33 - 10:54)

- **数据集背景**：数据来自 Kaggle，包含 **29** 个经过 PCA 匿名化处理的特征（V1-V28, Amount），以及时间（已剔除）和标签（0代表正常，1代表欺诈）。
- **极度不平衡**：正常交易多达 **284,000** 余笔，而欺诈交易仅有约 **500** 笔 。
    
- **传统解法 vs 本课解法**：通常面对不平衡数据会使用过采样（Oversampling）或欠采样（Undersampling），但考虑到极端的不平衡比例，本课转而使用自编码器进行异常检测 。
    
- **数据打乱与分割**：真实数据中标签往往是按顺序排列的（先是0，后是1），因此在训练前必须使用 `sample(frac=1)` 彻底打乱数据 。我们选取了 **250,000** 条**纯正常数据**作为训练集，剩余的正常数据与全部欺诈数据混合作为测试集 。
#### 2. 自编码器 (Autoencoder) 的核心原理 (11:08 - 14:20)

- **架构设计**：自编码器包含**编码器（Encoder）和解码器（Decoder）**。它将高维输入压缩成低维的“代码（Code）”，然后再将其展开回原始尺寸 。
    
- **学习目标**：模型致力于学习输入到输出的恒等映射（Identity Transformation），即让输出尽可能等于输入 。中间的代码层迫使模型学习数据的压缩表示和内在模式 。
    
- **模型构建 (PyTorch)**：网络由全连接层组成，使用 `ELU` 激活函数 。维度变化为：**29 -> 16 -> 8 -> 4 -> 2**（编码阶段），再从 **2 -> 4 -> 8 -> 16 -> 29**（解码阶段）。
##### 这个自编码器训练完成后，如果输入是欺诈信息，输出会更趋向于正常信息吗，所以误差才会大？

简单来说：**是的，当输入欺诈信息时，自编码器会根据它仅有的经验，拼命试图把它“重构”成一个正常的交易信息，从而导致原始输入和重构输出之间产生了巨大的差异（误差大）。**

作为你的助教，我来帮你把这个直觉转换成更严谨的理论支撑：

###### 为什么会“趋向于正常信息”？

**1. 模型的“世界观”里只有正常数据** 在训练阶段，我们刻意**只把合法的、正常的交易数据喂给模型** 。这意味着，模型内部的权重矩阵（Weights）完完全全是为了“如何完美重构正常数据”而优化的 。它的解码器（Decoder）本质上变成了一个**“只会生成正常交易的生成器”**。

**2. 强行把“异常”压缩进“正常”的模具里** 当一条带有诡异特征的欺诈数据 $X$ 进入模型时，编码器（Encoder）会被迫把它压缩进极度狭窄的潜在空间（本课中是压缩到了 2 维）。因为模型没学过如何保留“欺诈特征”，在降维压缩的过程中，那些关键的异常特征往往会被作为“无法识别的噪声”直接丢弃掉 。

**3. 用正常的经验去解码** 接下来，解码器（Decoder）拿到了这个降维后的代码（Code），它只能按照它所掌握的“正常交易的规律”去进行反向还原 。因此，模型最终输出的 $X'$，实际上是**模型在自己所知道的“正常数据流形（Manifold）”上，找到的距离这个欺诈数据最近的一个“正常交易的影子”**。

###### 误差为什么大？

因为输入 $X$ 是实打实的**欺诈交易**（比如异地大额连刷），而输出 $X'$ 被模型强行画成了一个**正常的交易**（比如日常小额消费），这两个向量在空间中的距离非常遥远。 当我们计算均方误差（MSE）：$|| [cite_start]X - X' ||^2$ 时，结果自然就会变得非常大

---
#### 3. 模型训练与异常检测逻辑 (22:06 - 29:20)

- **仅在正常数据上训练**：这是重中之重。我们将没有标签的纯正常数据喂给模型，让其专门学习“合法交易”的正常行为模式 。
    
- **损失函数**：因为输出是连续的数值而不是分类概率，这是一个回归问题，所以使用均方误差（MSELoss）进行训练 。
    
- **检测机制**：训练好的模型在重建正常的测试数据时，均方误差（MSE）会很小；而当它遇到从未见过的欺诈数据时，由于缺乏对应的重建模式，MSE 会变得很大 。
#### 4. 阈值设定与业务权衡 (29:28 - 32:48)

- **阈值（Cut-Off）选择**：我们假设误差分布服从正态分布，并计算 Z-score，将超过 **3** 个标准差的样本标记为欺诈 。
- **假阳性 vs 假阴性**：老师特别强调了业务上的权衡。将正常交易误判为欺诈（假阳性 / False Positive）仅仅是需要人工核实，代价较小；但如果将欺诈交易误判为正常（假阴性 / False Negative），就会造成实际损失 。因此，模型宁愿牺牲一些精确率（Precision），也要尽量提高召回率（Recall）。

## 👨‍🏫 教师重点复述 (考试/实战高频考点)

- **⚠️ 重点 1：不要对异常检测的训练集混入异常数据。** 老师反复强调，训练**只能**在干净（Clean/Legitimate）的数据上进行 。
- **⚠️ 重点 2：训练前必须 Shuffle 数据。** 老师特意指出，如果不打乱数据，模型会学习到数据的排序模式（比如全是0的序列），这会毁掉训练效果 。
    
- **⚠️ 重点 3：这不再是分类任务。** 不要习惯性地使用 CrossEntropy，自编码器的输出是重构数值，必须使用回归的 Loss（如 MSE） 。

## 🔤 专有名词与公式解析

- **MinMaxScaler (最小最大归一化)**：帮助模型更快收敛的预处理手段 。
    
    $$X_{std} = \frac{X - X_{min}}{X_{max} - X_{min}}$$
- **第一步：平移（分子 $X - X_{min}$）**
    
    假设你班上的考试成绩是从 40 分到 100 分。减去最小值 40 之后，所有人的成绩就变成了从 0 分到 60 分。这一步的作用是**把数据的起点“按”到 0**。
    
- **第二步：缩放（分母 $X_{max} - X_{min}$）**
    
    接着，用平移后的分数除以全班的“分差极差”（100 - 40 = 60）。考了 100 分（最高分）的人，公式变成 60 / 60 = 1；考了 40 分（最低分）的人，变成 0 / 60 = 0；考了 70 分的人，变成 30 / 60 = 0.5。这一步的作用是**把数据的跨度像拉橡皮筋一样，精准地按比例压缩到 0 到 1 之间**。
    
    $$X_{scaled} = X_{std} \times (max - min) + min$$
    就是把这个 $[0, 1]$ 的基础比例，**映射（定制）到你想要的任何目标区间 $[min, max]$ 中**。

我们可以把它拆解成两个非常直观的动作：**“拉伸（缩放）”** 和 **“垫高（平移）”**。
**但什么时候它会派上大用场呢？**

1. **适配特定的激活函数**：比如你神经网络用的是 `Tanh` 激活函数，它的输出范围是 $[-1, 1]$。为了让输入数据更好地配合它，你可能希望把输入数据的特征缩放到 $[-1, 1]$ 之间。这时候你只需要设置 $min=-1, max=1$，这条公式就能瞬间把数据映射过去。
    
2. **图像处理**：如果你在处理灰度图像，神经网络输出的可能是 $[0, 1]$ 之间的浮点数，但为了保存成真实的图片文件（像素值通常是 $0$ 到 $255$），你就可以用这个公式，设置 $min=0, max=255$，把网络输出完美还原成图片像素颜色！

    
- **MSE (Mean Squared Error, 均方误差)**：用于衡量输入与模型重构输出之间的差异 。
    
    $$MSE = \frac{1}{n}\sum_{i=1}^{n}(X_i - Y_i)^2$$
    其中
	- x：原始 transaction features
	- $$\hat{x}：$$ autoencoder reconstructed features
	- d=29：本 notebook 中 drop 掉 Time 和 label 后的 feature 数
	
	**为什么重要**：  
	MSE 是判断 anomaly 的分数。MSE 小表示模型熟悉这个输入；MSE 大表示模型不擅长还原这个输入。
	
	**notebook 中如何做**：  
	训练时用 `MSELoss()`，并计算每个 sample 的 feature-wise MSE。
	
	**常见误区**：  
	MSE 不是 classification accuracy。MSE 只是 anomaly score，最后还需要 threshold 才能得到 fraud / clean decision。
## 1. MinMaxScaler为什么只能 fit training data？

因为考试/真实使用时，模型只能知道 **training data 的统计信息**。

如果你对 test data 也 `fit`，等于模型提前偷看了测试集的分布：

```
test set 里面最大值是多少？test set 里面最小值是多少？
```

这叫 **data leakage**。

虽然你没有直接偷看 label，但你偷看了 test data 的整体分布，所以评估结果会不真实。

## 2. 举个 fraud detection 的例子

假设训练集中的交易金额范围是：

```
training Amount:min = 0max = 1000
```

所以 scaler 学到：

```
X_min = 0X_max = 1000
```

现在 test set 里有一笔交易：

```
Amount = 900
```

用 training scaler：

900−01000−0=0.9\frac{900-0}{1000-0}=0.91000−0900−0​=0.9

所以模型看到：

```
900 -> 0.9
```

这很合理，因为 900 在训练分布里已经算比较大。
