- **ResNet 的残差连接（Skip Connections）**：

## 学习“恒等映射”为什么这么难？

这部分解释了为什么传统的“卷积+激活函数”组合无法原封不动地传递信息 。

- **推导：** 假设我们有一个卷积层，后面跟着一个 ReLU 激活函数（用 $\sigma$ 表示）。给定输入 $x$，输出可以写成 $y = \sigma(conv(x))$ 。
- **痛点：** 如果我们希望这一层什么都不做，即输出完全等于输入（这就是所谓的恒等映射），那么我们需要找到一种卷积核，使得 $x = \sigma(conv(x))$ 。
    
- **结论：** 幻灯片指出，这在数学上几乎是不可能的 。因为 ReLU 激活函数的特性是会把所有负数变成 0；所以只要输入 $x < 0$，不论卷积层怎么努力计算，经过 ReLU 后的输出绝对不可能等于一个负数 $x$ 。这就导致了深层网络极难学习到恒等映射。
    

## ResNet 破局的核心思想 (Basic idea)

既然直接学习恒等映射行不通，这页幻灯片给出了天才般的解决方案：

- **换个思路：** 学习恒等映射太难，那学习**“零映射 (zero map)”**总该容易了吧 ？只要把网络层的权重都训练成趋近于 0 就可以了。
    
- **重构公式：** 假设我们最终希望得到的完美映射是 $\mathcal{H}(x)$ 。我们不去直接学生硬的 $\mathcal{H}(x)$，而是定义一个“残差” $\mathcal{F}(x) = \mathcal{H}(x) - x$ 。
    
- **引入捷径：** 现在，我们让中间的神经网络层只去学习这个残差 $\mathcal{F}(x)$ 。为了得到最终结果，我们只需要在网络层的输出上**直接加上原始输入 $x$** 就可以了 。
- **最终实现：** 这个把 $x$ 加到输出上的操作，就是通过添加**跳跃连接 (skip connection)** 或称**捷径 (shortcut)** 来完成的 。

## 📖 详细知识点梳理 (按课程逻辑)

**1. 数据集与基础任务区分**

- **ImageNet 数据集**：常用于预训练的庞大数据集，包含数百万张图片和上千个类别 。
- **Top-1 vs Top-5 准确率**：由于图像中可能存在多个物体，或者类别极为相似（如不同品种的梗犬），竞赛通常使用 Top-5 准确率 。只要真实标签存在于模型预测的前五个概率最高的类别中，即算预测正确 。
- **三大视觉任务**：图像分类（图片里是什么）、单目标定位（用边界框标出目标在哪）、目标检测（图片里有哪些目标，它们分别在哪） 。

**2. 早期经典网络：AlexNet 与 VGG**

- 这两个网络主要由“卷积层 + 池化层”交替堆叠，最后接全连接层构成 。
    
- VGG 更加深层（达到了19层），但基本构建块与我们基础学习的非常相似 。![[Pasted image 20260301141731.png]]
    

**3. ResNet (残差网络) 与网络退化问题**

- **退化问题**：随着网络层数增加，训练误差和测试误差反而升高，这并非由过拟合引起，而是网络难以优化 。
    
- **残差模块**：如果目标映射是 $\mathcal{H}(x)$，ResNet 让网络层去学习残差 $\mathcal{F}(x) = \mathcal{H}(x) - x$ 。然后将输入 $x$ 通过跳跃连接直接加到输出上，得到 $\mathcal{F}(x) + x$ 。 如果 $\mathcal{F}(x)$ 学成 0，该层就变成了一个完美的恒等映射 。
- **全局平均池化 (Global Average Pooling, GAP)**：ResNet 摒弃了传统的展平（Flattening）操作，改为对每个通道的特征图取平均值 。这在 ResNet-34 中将分类器前的参数量从约 2510 万骤降至约 50 万，极大提升了速度并减少了过拟合 。![[Pasted image 20260301143652.png]]

**4. GoogLeNet 与 Inception 模块**

- **网络中的网络**：Inception 模块将 $1\times1$、$3\times3$、$5\times5$ 卷积和最大池化并行操作，然后将它们的输出在通道维度上拼接（Concatenation） 。![[Pasted image 20260521152053.png]]
- **降维魔法**：在进行大尺寸卷积（如 $3\times3$ 或 $5\times5$）之前，先使用 $1\times1$ 卷积来减少通道数(原理是卷积操作后的通道数是由卷积核的数量决定的) 。这使得 Inception 模块的计算量从朴素版本的 3.03 亿次操作骤降至 1.28 亿次操作 。
- **辅助分类器 (Auxiliary Classifiers)**：在网络的中间层（如 4a 和 4d）附加了额外的 Softmax 分类器 。它们的作用是在训练时注入额外的梯度以缓解梯度消失问题，并起到正则化的作用；在推理阶段这些输出会被丢弃 。


**5. FID (Fréchet Inception Distance) 评估生成模型**

- **特征提取**：将 Inception-v3 网络的最后分类层去掉，使用其倒数第二层（全局平均池化层）输出的 2048 维向量作为图像的“语义特征” 。
- **语义比较**：FID 比较的是“真实图像集”和“生成模型生成的图像集”在这 2048 维特征空间中的统计分布（均值差异和协方差差异） 。距离越小，说明生成的图像质量越高、越逼真 。

**6. 目标检测的评估指标**

- **IoU (交并比)**：预测边界框与真实边界框的“交集面积”除以“并集面积” 。 通常 IoU 大于 0.5 才被认为是成功定位 。
    ![[Pasted image 20260521153227.png]]
- **mAP (平均精度均值)**：结合了分类正确性和边界框定位准确性 。它计算的是精度-召回率（Precision-Recall）曲线下的面积 。

## 🔤 专有名词与核心公式

- **卷积输出尺寸公式**：$H_{o} = \lfloor\frac{H_{i} + 2P - F}{S}\rfloor + 1$ 。其中 $H_i$ 是输入尺寸，$P$ 是填充 (Padding)，$F$ 是卷积核尺寸 (Filter)，$S$ 是步长 (Stride) 。
- **Precision (精确率)**：预测为正的样本中，真实为正的比例。公式：$TP / (TP + FP)$ 。
    
- **Recall (召回率)**：真实为正的样本中，被成功预测出来的比例。公式：$TP / (TP + FN)$ 。

## 💻 工程实现参考 (PyTorch 伪代码)

为了让你对 **ResNet 的残差连接** 和 **GAP** 有更直观的工程理解，这里提供一个简单的 PyTorch 构思片段：

Python

```
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, in_channels, out_channels):
        super(ResidualBlock, self).__init__()
        # 保持空间维度不变的卷积 (Padding=1, Stride=1, Kernel=3)
        self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, stride=1, padding=1)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, stride=1, padding=1)
        
    def forward(self, x):
        identity = x # 保存输入，用于跳跃连接
        
        out = self.conv1(x)
        out = self.relu(out)
        out = self.conv2(out)
        
        out += identity # 跳跃连接：F(x) + x
        out = self.relu(out)
        return out

# 全局平均池化 (GAP) 的简易实现
# 输入特征图大小假设为 [Batch, Channels, 7, 7]
gap_layer = nn.AdaptiveAvgPool2d((1, 1)) 
# 输出将变为 [Batch, Channels, 1, 1]，随后用 torch.flatten() 转为向量即可连接全连接层
```

## 📇 期末复习速查卡 (可直接复制到笔记)

- **Q: 为什么 ImageNet 挑战赛通常看 Top-5 准确率？**
    
    - A: 因为图像可能包含多个物体，或者类别（如狗的品种）极为相似，人类都难以分辨，Top-5 容错率更合理 。
- **Q: ResNet 是如何解决深层网络极难训练的问题的？**
    
    - A: 引入了 Skip Connection（跳跃连接），使网络层学习输入与输出之间的残差（Residual）而非完整的映射，让学习“什么都不做（恒等映射）”变得简单 。
        
- **Q: 全局平均池化 (GAP) 相比于 Flatten 展开有什么优势？**
    
    - A: 极大地减少了全连接层所需的参数量（减少千万级别），不仅加速计算，还能有效防止过拟合 。
        
- **Q: 评估目标检测框准不准用什么指标？**
    
    - A: 交并比 (IoU)，即预测框与真实框的重叠面积除以它们的合并总面积，通常要求 >0.5 。
