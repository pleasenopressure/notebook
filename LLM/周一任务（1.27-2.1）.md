#### 模块 B：Agent loop 工程化注释（关键）

**输入**

- `orchestration/react_loop.py`
    

**行动**

- 在 `run_react` 中为以下点加 **工程注释（不是算法解释）**：
    
    - 为什么 system prompt 每次重建
        
    - 为什么 history 过滤 system
        
    - 为什么 Observation 作为 user message 回灌
        
    - 为什么 max_steps 是硬上限
        

**输出**

- 高质量注释（面试官看得懂）
    

**DoD**

- 面试时你能回答：
    
    > “为什么不用 function calling，而是 JSON action？”
    我选择 JSON action 是为了**跨模型一致性与可控性**。不同模型/SDK 的 function calling 支持差异大，而且 tool schema、streaming、错误处理在不同平台行为不一致。JSON-only 协议让解析稳定、失败显式、日志可回放；工具执行由 ToolRunner 治理（timeout/retry/cancel），模型只负责“选择动作”，系统负责“执行动作”。
