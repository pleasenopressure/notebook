# 这个课的ppt做的挺好的，最好结合复习
## 📚 课程概览 (Course Overview)

本节课深入探讨了**深度学习在自然语言处理中的核心架构：循环神经网络（RNN）** 。课程从传统机器学习处理变长序列的痛点出发，详细推导了简单 RNN 的结构、张量形状变化，以及它在语言模型、序列标注和文本分类三大任务中的具体应用 。最后，针对长距离依赖和梯度问题，课程引入了进阶的堆叠 RNN、双向 RNN 以及工业界常用的 LSTM 与 GRU 结构 。

## 📖 按章节详细讲解与考点拆解

#### 1. 为什么需要 RNN？(Slide 3 | Transcript @0:00-4:10)

- **传统方法的局限：** 传统的监督式机器学习（如多层感知机 MLP 或条件随机场 CRF）需要固定长度的输入张量 。由于句子的长度是可变的，传统方法通常采用“滑动窗口（Sliding Window）”策略来妥协 。
    
- **滑动窗口的致命伤：** 老师在课堂上举例，自然语言中常有从句结构，导致相关的词语被隔开很远（长距离依赖） 。由于窗口大小固定，前一个窗口的决策对后续窗口没有影响，很难学习到长距离的语义模式 。
    

#### 2. 简单循环神经网络 (Simple RNN) 的机制 
- **核心创新：** RNN 引入了“记忆（Memory / Context）”机制，隐藏层不仅接收当前时刻的输入 $x_t$，还接收上一个时刻的隐藏层状态 $h_{t-1}$ 。
    
- **计算公式：** 隐藏层输出 $h_t = g(U h_{t-1} + W x_t)$，其中 $g$ 为激活函数（如 tanh 或 ReLU），$U$ 为记忆权重矩阵，$W$ 为当前输入权重矩阵 。预测输出 $y_t = f(V h_t)$，通常 $f$ 为 Softmax 。

- **沿时间展开 (Unrolling)：** 在计算损失和反向传播时，现代深度学习框架（如 PyTorch）会将 RNN 沿时间步展开（Unroll in time） 。
* **记忆衰减：** 老师特别指出，虽然 RNN 有记忆，但随着序列变长，早期词汇的贡献会随时间指数级衰减 。

#### 3. RNN 的三大核心应用 (Slides 8-13 | Transcript @25:00-30:00)

- **序列标注 (Sequence Labeling)：** 如词性标注（POS tagging）。输入序列与输出序列是 1 对 1 映射 。每个时间步都输出一个预测（如名词、动词） 。
- **生成模型 / 语言模型 (Autoregressive Generation)：** 如问答系统。输入前文，预测下一个词，并将预测出的词作为下一个时间步的输入 。
- **序列分类 (Sequence Classification)：** 如情感分析或文档分类。重点：**只使用最后一个时间步的隐藏层状态 $h_n$** 作为整个输入序列的表示，将其送入分类器（如全连接层 + Softmax）得出最终类别（如正向/负向） 。
    
#### 4. 进阶架构：处理深层与长程语义 (Slides 14-20 | Transcript @30:00-37:00)

- **堆叠 RNN (Stacked RNNs)：** 将一个 RNN 层的整个输出序列作为另一个 RNN 层的输入，这标志着进入“深度学习”范畴，能够编码更抽象的特征 。

	核心概念拆解：什么是堆叠 RNN？
	
	正如老师在课堂上提到的，“一层网络只是机器学习，多于一层才算进入了深度学习（Deep Learning）的范畴” 。
	
	在单层 RNN 中，输入是单词的嵌入向量（Word Embeddings），输出是隐藏层状态（Hidden States），然后直接接入 Softmax 分类器得出结果。
	
	而在**堆叠 RNN**中，我们像盖楼一样把多个 RNN 层叠在一起 ：
	- **第一层 (RNN 1)**：接收原始的词嵌入向量（如 $x_1, x_2, x_n$）作为输入，经过计算后，输出第一层的隐藏层状态。**注意老师的强调：此时我们不使用 Softmax** 。
	- **第二层 (RNN 2)**：将 RNN 1 的整个隐藏层输出序列，直接作为自己的输入 。这里的输入不再是代表单个单词的词向量，而是包含了单词及其初步上下文信息的“高维表示” 。
	- **第三层 (RNN 3)**：将 RNN 2 的输出作为输入。在最后一层，我们才将输出接入 Softmax 分类头来进行最终的预测（比如分类或生成下一个词） 。

    
- **双向 RNN (Bi-Directional RNNs)：** 结合从左到右的前向状态 $h_t^f$ 和从右到左的后向状态 $h_t^b$ 。老师强调，最终拼接张量 $h_t = h_t^f \oplus h_t^b$（在 PyTorch 中内存占用会翻倍），这有助于捕捉句子首尾的双向上下文 。
    ![[Pasted image 20260531203527.png]]![[Pasted image 20260531203537.png]]
- **LSTM 与 GRU：**
    
    - 为了解决深层网络训练时的**梯度消失 (Vanishing gradients)** 和 **梯度爆炸 (Exploding gradients)** 问题 。
    - **LSTM (长短期记忆网络)：** 引入了长期细胞状态 $c_t$ 和短期隐藏状态 $h_t$ 。通过“遗忘门(Forget gate)”、输入门和输出门来控制信息流 。 
    * **GRU (门控循环单元)：** 将长短期状态合并，结构更简单（门更少），在很多任务上性能媲美 LSTM 且计算更高效 。

## 🚨 教师重点复述 (TA 敲黑板)

1. **必须要自己动手推演张量形状 (Tracking Tensor Shapes)！**
    
    - **老师原话重点：** “建议大家课后去走一遍这些张量的形状，说服自己它们是成立的... 这是你构建自己的模型时必须掌握的技能。” (@17:57)
        
    - **助教补充：** 课堂给出了详细推导：One-hot 输入是 \[1, $|V|$] $\rightarrow$ Embedding 权重是\[$|V|$, $d_{embed}$] $\rightarrow$ 词向量是\[1, $d_{embed}$] $\rightarrow$ 隐藏层输出是\[1, $d_{hidden}$] $\rightarrow$ 经过分类头 (Classifier Head) 输出 Logits 为\[1, $|V|$] 。写 PyTorch 代码时，如果 `RuntimeError: size mismatch`，通常就是没理解透这里的形状映射。
        
2. **训练技巧：教师强制 (Teacher Forcing)**
    
    - **概念辨析：** 在训练语言模型（预测下一个词）时，即使模型上一步预测错了，在下一个时间步，我们依然把**真实的标签 (Ground Truth)** 作为输入喂给模型，而不是用它自己预测的错误结果 。
    - **老师强调原因：** 如果不用 Teacher Forcing，模型一旦预测错一个词，后续路径就会彻底跑偏，导致难以收敛且训练极其缓慢 。
        
3. **何时使用 LSTM vs GRU？**
    
    - **老师建议：** 先尝试默认模型；如果发现 LSTM 提升不大，可以切换到 GRU。GRU 参数更少，占用显存更小，计算更快 。

## 🗂️ 专有名词与公式速查卡

|**术语 / 公式**|**中文翻译**|**直观解释与工程含义**|
|---|---|---|
|**Logits**|逻辑值 / 原始输出|神经网络分类头的最后一层输出（通常是实数），**还未经过 Softmax 归一化** 。在 PyTorch 中，`CrossEntropyLoss` 会自带 Softmax，传入 Logits 即可 。<br><br>+4|
|**Softmax**<br><br>+1|Softmax 函数|将任意实数向量（Logits）转化为加和为 1 的概率分布 。<br><br>+1|
|**Argmax**<br><br>+1|最大值索引|取出 Softmax 概率分布中最大值所在的“位置索引”，以此决定最终预测的类别 / 词汇 。<br><br>+2|
|**$h_t = h_t^f \oplus h_t^b$**<br><br>+1|双向状态拼接|符号 $\oplus$ 表示**拼接 (Concatenation)**。前向隐藏向量和后向隐藏向量拼接后，特征维度变为单向的 2 倍 。<br><br>+1|
|**Cross-entropy Loss**|交叉熵损失|衡量模型预测的概率分布与真实标签的 One-hot 分布之间的差距。常用于多分类和生成任务 。公式涉及 $-\sum y_k \log(\hat{P}_k)$ 。<br><br>+1|
