本节课主要探讨了**计算机视觉中的降维技术**，巧妙地将线性代数中的核心概念（协方差、特征值、特征向量）与实际的图像处理应用（主成分分析 PCA、特征脸 Eigenfaces）结合起来 。课程的目标是教你如何在海量的像素数据（例如 20,000 维的图像）中提取出最具区分度的“关键特征”，并通过去除冗余信息来实现数据的极大压缩，同时保留图像的主要视觉辨识度 。

## 🚨 教师重点复述 (Key Takeaways & Emphasized Points)

老师在课堂上反复强调了以下几个极其重要的实操与理论重点：

- **不要手工计算特征分解 (Don't compute eigendecomposition by hand)**：
    
    - **原因**：对于超过 $5\times5$ 的矩阵，手工计算逆矩阵或特征值极其耗时且几乎不可能完成 。在图像处理中，特征向量往往有成百上千维 。
    - **应对方案**：强烈建议直接调用现成的数学或机器学习库（如 Python、C++ 中的相关库）来完成特征分解 。调用库函数时，它们通常会自动按特征值的大小（从大到小）对特征向量进行排序 。
        
- **均值中心化是绝对必要的前提 (Mean-centering is critical)**：
    
    - **原因**：真实数据通常会带有某种“偏移（bias）”或未对齐在原点 。如果不做均值中心化直接计算，数据分布的形状将被扭曲 。
    - **操作**：通过减去均值，将所有数据的平均位置平移到坐标系原点，以便纯粹地衡量数据的分布形状 。
      这里注意，每一行是一条待中心化的数据，这里需要计算每一列的feature的均值，然后减掉每一行的对应feature。
      ![[Pasted image 20260301180057.png]]
- **记住协方差矩阵是“对称矩阵” (Symmetric property of Covariance Matrix)**：
    
    - **原因**：老师明确提示这是一个非常重要的属性 。由于实对称矩阵的优秀数学性质，它的特征向量必然是相互正交（互相垂直）的 。这为我们寻找新的、互不相关的坐标基底（主轴）提供了数学保障 。

## 🧠 详细内容与知识点拆解

#### 1. 协方差与协方差矩阵 (Covariance & Covariance Matrix)

- **方差 (Variance)**：衡量单一变量数据的离散程度（数据分布有多宽） 。
- **协方差 (Covariance)**：衡量两个变量如何协同变化 。例如，身高和体重通常具有正协方差（一起增加），而某些无关特征（如是否戴眼镜与性别）的协方差可能接近 0 。以下可以直观理解方差和协方差。
    ![[Pasted image 20260301175142.png]]
- **协方差矩阵 (Covariance Matrix, $\Sigma$)**：编码了高维数据集中所有可能维度对之间的协方差 。
    
    - 如何计算（实操步骤）：
        
        1. 计算每个维度的均值并减去它（均值中心化），得到矩阵 $Z$ 。
        2. 计算 $\Sigma \propto Z^T Z$ 。
            
#### 2. 特征值与特征向量 (Eigenvalues & Eigenvectors)

- **核心等式**：$A\upsilon = \lambda\upsilon$ （老师标注为非常重要的公式！） 。
- **几何直观**：如果 $A$ 是协方差矩阵，那么找出的特征向量 $\upsilon$ 就是数据的**主轴 (Principal Axes)** 。
    
- **特征值 $\lambda$ 的意义**：它代表了数据在对应特征向量方向上的方差大小（即该方向的重要性） 。最大的特征值对应的特征向量，就是包含最多数据信息的第一主成分（First P.C.） 。
#### 3. 主成分分析 (PCA) 完整算法流程

PCA 是一种正交线性变换，用于将数据映射到一个由其主轴定义的新空间中 。

- **Step 1**: 将所有数据向量进行均值中心化 。
    
- **Step 2**: 组合成矩阵 $Z$ 。
    
- **Step 3**: 对 $Z^T Z$ 进行特征分解（Eigendecomposition），得到特征向量矩阵 $Q$ 和对角特征值矩阵 $\Lambda$：$Z^T Z = Q \Lambda Q^T$ 。
    
- **Step 4**: 按特征值降序对 $Q$ 的列进行排序 。
    
- **Step 5**: 保留前 $L$ 个最大的特征向量，形成降维转换矩阵 $Q_L$ 。
    
- **Step 6**: 将原始数据投影到低维空间：$T_L = Z Q_L$ 。
    
- _降维的好处_：去除低方差（不重要）的维度，实现数据压缩，例如将 100 维压缩到 10 维 。

#### 4. 视觉应用：特征脸 (Eigenfaces)

- **痛点**：直接将 $100 \times 200$ 的图像展平为 20,000 维的向量，不仅计算量大，而且对光照、位置偏移和噪声极其敏感 。
    
- **对齐与预处理**：必须要求面部朝前、位置居中，尺寸统一 。
- **PCA 降维**：通过计算一组人脸图片的“平均脸 (Mean-face)”并减去它 ，接着运用 PCA。我们可以用极少量的数字（例如 10 个、62 个或 250 个数字）来完美替换原本的 20,000 个像素点，且仍能以极高保真度重建和识别出原始人脸 。

## 💻 工程实现视角 (Python 伪代码与超参数)

在实际工程中，你可以使用 `numpy` 或直接调用 `sklearn`，无需自己推导逆矩阵。

Python

```
import numpy as np

# 假设 X 是图像数据集，形状为 (N, 20000)，N为图片数量
# Step 1: 均值中心化
mean_face = np.mean(X, axis=0)
Z = X - mean_face

# Step 2: 计算协方差矩阵 (注意：实战中若 N << 20000，可用 SVD 优化计算)
# 这里演示标准概念:
cov_matrix = np.cov(Z, rowvar=False) 

# Step 3: 特征分解
eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)

# Step 4: 降序排列
idx = np.argsort(eigenvalues)[::-1]
eigenvectors = eigenvectors[:, idx]

# Step 5: 取前 L 个主成分 (如 L=62)
L = 62 # 这个是关键的超参数（压缩率）
Q_L = eigenvectors[:, :L]

# Step 6: 将图像压缩投影到低维空间
T_L = np.dot(Z, Q_L) # 输出形状: (N, 62) -> 完美实现降维！
```
