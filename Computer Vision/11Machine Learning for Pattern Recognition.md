## 📌 课程精炼摘要

本节课介绍了计算机视觉中模式识别的机器学习基础 。课程核心分为三部分：特征提取与特征空间（如何将图像转化为机器可读的向量）、距离与相似度度量（如何比较特征），以及监督学习（如线性分类器、SVM、KNN）与无监督学习（如 K-Means 聚类）的基本原理和局限性 。

## 💡 教师重点复述（课堂高频强调与关键难点）

老师在课堂音频中反复强调了以下几个极具实战意义的重点，这些也是考试和工程实践中最容易踩坑的地方：

- **语义鸿沟 (Semantic Gap)**：人类看到的是人脸、猫狗或环境的上下文（如点彩画派的作品或树上的错觉图） 。但机器看到的是一堆 0 和 1 组成的像素数组（例如将图像转换为 8位二进制或 0-255 的亮度值） 。理解这种感知差异是设计好算法的前提 。
    
- **假阳性 (FP) vs 假阴性 (FN) 的权衡**：这是分类器设计中的核心考量 。老师特别举了医疗影像检测癌症的例子：宁可增加假阳性（误诊，后续可复查），也绝不能容忍假阴性（漏诊，可能致命） 。因此，决策边界（Decision Boundary）并不总是死板地处于正中间，而是要根据具体任务的代价来调整 。
- **过拟合 (Overfitting)**：如果使用过于复杂的非线性边界将训练集完美分开，可能会导致分类器对新数据的泛化能力极差 。
    
- **KNN 的 K 值选择**：在 K 近邻算法中，K 值最好设为奇数（Odd number），以避免出现平局（Tie-breaker）导致无法分类的尴尬情况 。同时，KNN 对于庞大的数据集来说计算代价极为昂贵，因为它需要计算与所有样本的距离 。
- **K-Means 的初始化敏感性**：最终的聚类结果非常依赖于初始种子点（Seed points）的随机选择 。

## 📖 按章节详细讲解

**一、 引入与特征提取 (Slides 5-13 | Audio 10:00-18:00)**

- **工作流**：典型的机器视觉系统流程是：输入图像 -> 特征提取器 -> 机器学习 -> 输出结果 。
- **特征向量 (Feature Vector)**：是一个具有固定元素数量的数学向量 。它代表了特征空间中的一个点或方向 。
    
- **皮卡丘提取示例**：老师以皮卡丘为例，说明了在没有语义解释的情况下，可以提取图像尺寸（不推荐）、RGB 颜色均值（如蓝色、绿色、红色分量）、均值与标准差，或颜色直方图作为特征向量 。所有特征向量的维度必须固定 。
**二、 距离与相似度 (Slides 14-18 | Audio 18:00-22:30)**

- 高质量的特征空间中，相似的输入应当距离相近，不同的输入应当距离较远 。
- **欧氏距离 (L2 Distance)**：最直观的直线距离 。
    
- **曼哈顿距离 (L1 Distance)**：沿坐标轴平行的路径距离 。
    
- **余弦相似度 (Cosine Similarity)**：衡量两个向量之间夹角的余弦值，它不是一种距离 。当你不在乎向量的相对长度时非常有用，例如用来比较色相 (Hue) 值 。
**三、 监督学习与分类 (Slides 21-33 | Audio 23:50-41:00)**

- **分类器**：利用预先标注好的训练数据，学习如何为向量分配类标签 。
- **线性分类器与 SVM**：尝试学习一个超平面（Hyperplane）来将特征空间划分为两部分，以最小化错误 。支持向量机（SVM）是常用的算法之一 。
- **KNN (K-Nearest Neighbours)**：通过计算未知数据点与训练集中所有点的距离，找出最近的 K 个邻居，并根据这 K 个邻居的多数类别来决定新数据的类别 。
  - KNN 的标准工作流程

1. **设定 K 值**：决定你要参考周围多少个邻居的意见 。
2. **计算距离**：当输入一个新图像或新特征向量时，机器会计算这个新点与训练集中**每一个**样本点的距离 。
3. **寻找近邻**：将算出的距离从小到大排序，挑选出距离最近的 K 个点 。
    
4. **投票表决**：统计这 K 个邻居的类别标签，采取多数表决制（Majority Voting），票数最多的类别就是预测结果 。
**四、 无监督学习与聚类 (Slides 34-37 | Audio 41:00-46:00)**

- **聚类 (Clustering)**：在没有任何预先标记知识的情况下对数据进行分组 。
    
- **K-Means 算法步骤**：
    
    1. 选择组数 K 。
        
    2. 随机选取 K 个初始聚类中心 。
        
    3. 将每个点分配给最近的聚类中心 。
        
    4. 将聚类中心重新计算为分配给它的所有点的平均值 。
        
    5. 重复上述步骤，直到聚类中心不再移动 。
