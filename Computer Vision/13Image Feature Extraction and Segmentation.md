# 计算机视觉核心笔记：图像特征提取与图像分割 (Computer Vision Core Notes: Image Feature Extraction and Segmentation)

## 1. 课程概览 (Course Overview)

本部分课程聚焦于计算机视觉中的两个基础且核心的任务：**图像特征提取（Image Feature Extraction）**与**图像分割（Image Segmentation）** 。从最宏观的全局统计特征，到依赖于分割技术的区域特征，再到精准定位的局部特征，特征的形态决定了视觉系统理解图像的方式 。同时，为了获取高质量的区域特征，我们必须依赖鲁棒的图像分割技术（如自适应阈值、K-Means等），并利用连通域标记算法将离散的像素聚合为具有独立语义的物体 。

---

## 2. 图像特征的形态与层级 (Image Feature Morphology and Hierarchy)

在特征提取器（Feature Extractor）的黑盒中，输入原始图像，输出特征向量（Feature Vectors）。根据对图像的处理粒度，特征主要分为以下四种形态 ：

- **全局特征 (Global Features)**：将整幅图像作为一个整体进行分析，仅提取出一个单一的特征向量 。例如全局颜色直方图 。
    
- **网格/块特征 (Grid or Block-based Features)**：将整张图像机械地切割成固定大小的规则网格块，从每个网格块中提取一个特征，输出与网格数量相等的多个特征向量 。
    
- **区域特征 (Region-based Features)**：基于语义或视觉相似性，首先将图像分割（Segmentation）成多个有意义的区域（Segments），然后为每个区域提取一个特征 。
    
- **局部特征 (Local Features)**：首先在图像中检测出兴趣点（Interest points / Keypoints），然后仅从这些点周围的像素邻域中提取特征 。输出特征的数量与检测到的局部兴趣点数量一致 。
    

---

## 3. 全局特征：颜色直方图 (Global Features: Image Histograms)

全局特征中最经典的是颜色直方图，它统计了图像中像素值的分布情况 。相比于独立统计 R、G、B 通道，**联合颜色直方图 (Joint-colour histograms)** 统计的是每种颜色组合（如 $R \times G \times B$）出现的次数 。

## 进阶解析：量化 (Quantization) 的必要性

联合颜色直方图面临一个严峻的“维度爆炸”问题：如果精确统计 $256 \times 256 \times 256$ 种颜色，特征向量将长达上千万维，这在工程上是极度低效的 。 解决这一问题的核心技术是**量化（Quantization）** 。人类的视觉系统实际上并不敏感于极其微小的颜色差异（例如 RGB 值为 `0, 1, 0` 和 `0, 1, 1` 的区别肉眼无法分辨）。因此，我们可以将 0-255 的颜色范围划分为更宽的“箱子（Bins）”，例如 0-50、50-100 作为一个区间 。量化通过合并视觉上相似的颜色，在不损失关键信息的前提下，极大地压缩了特征向量的维度 。

## 进阶解析：全局特征的不变性与空间信息丢失 (Invariance vs. Spatial Loss)

- **不变性优势**：
    
    - **尺度不变性 (Size Invariant)**：通过将每个 Bin 中的像素数除以图像总像素数（即归一化 Normalisation），直方图可以免受图像分辨率大小的影响 。
        
    - **光照与旋转不变性**：切换到特定的色彩空间（如 H-S 通道）可抵抗均匀的光照变化 ；同时，由于直方图只统计数量不计较位置，它天然具备**旋转不变性 (Invariant to rotation)** 。
        
- **致命缺陷（空间信息丢失）**： 全局直方图彻底剥离了像素的**空间分布（Spatial information）** 。例如，一张“卫星拍摄的地球图”和一张“杂乱散落的坚果图”，如果它们包含的颜色种类和像素比例碰巧一致，它们将产生**完全相同**的颜色直方图 ！这种只看整体不看局部的特性，使得全局特征无法区分视觉上截然不同的图像 。

## 4. 图像分割技术 (Image Segmentation Techniques)

为了获取更具描述力的“区域特征”，必须先进行图像分割——即将图像划分为共享特定视觉特征的像素集合（Segments）。

## 4.1 全局二值阈值与 Otsu 方法 (Global Binary Thresholding & Otsu's Method)

最简单快速的分割是**阈值化 (Thresholding)**，它将灰度图转化为黑白二值图 。**Otsu 方法**能够自动寻找最优阈值 。它的假设前提是图像包含两个清晰的类别（前景与背景，对应直方图上的双峰），通过穷举搜索，寻找能够使**类间方差（Interclass variance）最大化**的阈值 。 _局限性_：Otsu 方法极容易受到不均匀光照的影响 。如果图像一部分处在阴影中，单一的全局阈值会同时破坏亮部和暗部的信息 。

## 4.2 自适应/局部阈值 (Adaptive/Local Thresholding)

为了解决光照不均，**自适应阈值**应运而生。它不再使用单一的全局标准，而是为图像中的每一个像素单独计算一个阈值，计算依据是该像素周围的矩形窗口（Window）内的邻居像素 。 在均值自适应阈值 (Mean adaptive thresholding) 中：如果当前像素值小于“邻居均值 + 偏移量(constant offset)”，则设为 0（黑色），否则设为 1（白色） 。

#### 💡 难点剖析 1：偏移量 (Offset) 的底层机制与去噪原理

为什么不能单纯地只用“邻居均值”作比较，而必须引入一个 `Offset` 呢？它的核心使命是：消除纯色背景中的微小噪声 (Removing noise) 。

- **没有偏移量时的灾难（Offset = 0）**： 假设滑动窗口正处于一片纯黑色的阴影背景中。理想情况下，这里所有像素值都是 10。但受制于相机传感器噪声或微弱光线波动，像素值实际上在 8、9、11、12 之间随机起伏 。此时窗口的均值大概也是 10。 如果严格按照均值切割，值为 11 和 12 的像素因为大于均值 10，会被算法无情地误判为“白色前景”；而 8 和 9 被判为“黑色背景” 。结果就是，原本干净的纯黑背景，会被切割得支离破碎，产生密密麻麻的黑白噪点干扰 。
    
- **引入偏移量的魔法（例如 Offset = 6）**： 我们将判定阈值抬高，变为 `均值(10) + 偏移量(6) = 16` 。 此时，原本在黑暗中波动的噪点像素（8、9、11、12），统统小于 16，它们会被干净利落地强制判定为“黑色背景” 。而真正的前景（如白纸上的黑色文字对比），其亮度差远超这个偏移量，依然能被正确分割。
    
- **调参博弈 (Trade-off)**： 偏移量是一把双刃剑。如果 `Offset` 设定过高（及格线太高），图像中那些原本需要被提取的细微信息（如稍微偏淡的墨迹文字），就会因为达不到被抬高的阈值，而被系统当成背景抹除（完全变白），导致信息永久丢失 。
    

#### 💡 难点剖析 2：尺度问题 (Scale Problem) 与窗口大小的选择

决定自适应阈值成败的另一个关键参数是**窗口大小 (Window Size)** 。这引出了计算机视觉中最棘手的核心挑战之一：**尺度问题 (Scale Problem)** 。

以识别黑白二维码为例 ：![[Pasted image 20260525220445.png]]

1. **窗口太小（如 Size = 5）**：当极小的 5x5 窗口完全进入二维码的一个大黑色实心方块内部时，它看到的邻居全是黑色的 。它无法察觉自己身处黑暗之中，只能检测出颜色发生突变的“边缘”。结果，实心黑块变成了空心的白色方块，只留下一圈黑色轮廓 。
    
2. **看似完美的窗口（如 Size = 50）**：将窗口调大到 50x50 后，窗口终于大过了黑色方块的面积，算法成功将完整的实心黑块提取了出来 。
    
3. **尺度崩溃**：然而 50 并非万金油。如果人手将这个二维码**拿得离相机更近**，物理上的同一个黑色方块，在图像中占据的像素面积会急剧膨胀（即尺度变大）。此时，原本够用的 50x50 窗口相对于变大的黑块又显得“太小了”，实心黑块的中心会再次出现破洞 。 **结论**：在不知晓相机拍摄距离和物体物理尺寸的前提下，固定的窗口大小必然会在物体尺度发生变化时彻底失效 。
    

## 4.3 基于 K-Means 的图像分割 (Segmentation with K-Means)

除了阈值，聚类也是一种强力的分割手段 。

- **基础版本**：对所有像素的色彩向量（如 RGB 或更符合人类感知的 Lab 色彩空间 $[r,g,b]$）进行 K-Means 聚类，将像素分配给最近的簇中心 。
    
- **空间感知进阶**：朴素的颜色聚类会忽略像素的物理位置，导致画面两端完全不相邻但颜色相似的像素被强行归为同一类（违背了物体的空间连续性）。解决方案是将空间坐标整合进特征向量，变为 $[r, g, b, x, y]$ 。引入**空间权重 (Spatial weight)** 来缩放 x 和 y，权重越高，分割结果越倾向于空间上连贯的几何块；权重越低，则越倒退回纯粹的颜色聚类 。

## 5. 连通域标记 (Connected Component Labelling)

图像被分割成二值（前/背景）后，计算机仍不知道里面有“几个”物体。**连通域标记 (CCL)** 的任务就是找出所有相互连接的像素集合（Connected Component），并为每个独立集合贴上一个独一无二的标签（Label）。

- **像素连通性 (Pixel Connectivity)**：定义相邻的标准，分为 **4-连通 (4-Connectivity)**（仅看上下左右）和 **8-连通 (8-Connectivity)**（包含对角线像素）。
    

#### 💡 难点剖析 3：两遍扫描算法 (Two-pass algorithm / Union-Find) 的完整图解与推导

这是一个极具工程美感且极其高效的算法，因为它处理整张图像只需要从头到尾扫视**两遍** 。它的底层思想是数据结构中的**并查集 (Union-Find)** 。

**核心规则：光栅扫描与受限视野** 算法采用光栅扫描（Raster Scanning，从左到右，从上到下逐像素处理）。这意味着当处理当前像素时，在它的 8 个邻居中，计算机**只能看到已经扫描过的“过去”像素**（即左侧、左上、正上、右上四个位置）。![[Pasted image 20260525232026.png]]

- **第一遍扫描 (Pass 1)：局部贴标签，遇碰撞记账**
    
    1. 如果遇到背景（0），直接跳过 。
        
    2. 如果遇到前景（白色像素），检查其已扫描的邻居 ：
        
        - **情况 A（无依无靠 - 新区域）**：如果邻居全是背景，意味着发现了一块“新大陆”，为其分配一个新的数字标签（如 1、2、3）。
            
        - **情况 B（有邻接连通）**：如果邻居中存在标签，则将**最小的那个标签**赋值给当前像素，作为其归属 。
            
        - **情况 C（核心：标签碰撞 / Collision）**：如果当前像素不仅有多个邻居，而且这些邻居属于**不同的标签**（例如左边是区域 1，右上方是区域 2）。这意味着原本以为互相独立的两块大陆，在当前这个像素点“胜利会师”了！此时，不仅要将当前像素设为最小标签（1），还必须在一个名为**“等价表 (Equivalence Table)”**的账本中记录一笔关键信息：`标签 1 和标签 2 实际上是等价的，它们属于同一个物理连通域` 。 (第一遍结束时，由于形状的复杂性，同一个物理连通的物体上可能被贴满了 3、4、5、6、7 等各种临时标签，但在等价表中，它们已被锁定为一个家族 。)
            
- **第二遍扫描 (Pass 2)：查表统一，实现大一统**
- ![[Pasted image 20260525232104.png]]
    
    1. 算法首先整理等价表，为每个“连通家族”找出一个统一的最小“族长”标签（Lowest equivalent label）。例如，1 和 2 的族长是 1；3,4,5,6,7 的族长是 3 。
        
    2. 再次执行光栅扫描遍历整个图像数据 。遇到前景像素时，直接根据它的临时标签去查询等价表，并将其**重命名 (Relabel)** 为该家族的统一“族长”标签 。 (第二遍结束时，整张图上互相连通的像素块将被完美地赋予相同的数字标签，原本错综复杂的 3,4,5,6,7 全部被统一刷成了 3 。)
        

**直观隐喻**：

这就像一队探险家在迷雾中绘制岛屿地图（光栅扫描）。起初他们登陆了几个不同的海滩，分别命名为 1 号营地、2 号营地。随着迷雾继续散去，探险家们向内陆推进，突然发现 1 号营地和 2 号营地原来有一条小路相连！探险队长立刻在记事本（等价表）上记下：“1 和 2 实为同一个岛屿”。直到迷雾全散，探险队长翻开记事本，把同一个岛上的所有营地统一改名叫“一号岛”、“二号岛”（第二遍扫描）。这就是 Union-Find 算法在 CCL 中的浪漫体现。

## 6. 总结与工程实现参考 (Summary & Engineering Implementation)

通过特征形态的划分、基于光照和尺度考量的阈值与聚类分割算法，以及底层基于 Union-Find 的连通域标记，我们完成了让计算机从杂乱像素中提取和感知独立对象物体的全闭环 。

为了加深理解，以下是与上述底层逻辑完全对应的 OpenCV Python 代码实现参考：

Python

```
import cv2

# 1. Otsu 全局阈值 (Global Thresholding)
# 对应课件中寻找类间方差最大化的自动化阈值方法
ret, thresh_otsu = cv2.threshold(gray_img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 2. 均值自适应局部阈值 (Mean Adaptive Thresholding)
# blockSize 即 Window Size (需考虑尺度问题)
# C 即 Offset (核心作用: 滤除纯色背景波动的噪声)
thresh_adapt = cv2.adaptiveThreshold(gray_img, 255, cv2.ADAPTIVE_THRESH_MEAN_C, 
                                     cv2.THRESH_BINARY, blockSize=19, C=6)

# 3. 连通域标记 (Connected Components via Two-pass algorithm)
# connectivity 对应 4-连通 或 8-连通
# num_labels 返回独立物体的数量，labels 返回打好标签的矩阵
num_labels, labels = cv2.connectedComponents(thresh_otsu, connectivity=8)
```
