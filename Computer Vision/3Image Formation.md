### 📝 2. 核心内容梳理 (Detailed Breakdown)

#### A. 图像的数字表示：位与像素 (Bits & Pixels)

- **像素数据**: 图像是一个矩阵，通常以 **8-bit 无符号整数 (uint8)** 存储，范围是 $[0, 255]$ 。
    
    - _操作提示_: 在进行数学运算前，通常建议将数据转换为 **浮点数 (Float)** 。
        
- **位平面分解 (Bit Plane Decomposition)** [Slide 3-4]:
    
    - 如果我们把一个8位图像拆分成8个二进制层（相当于对整张图像进行了一次最“暴力”的**二值化（Binarization）**处理，不同的的二进制层对应不同的分割阈值）：
        
        - **最高有效位 (MSB, Bit 7) 携带最多的信息**:
    
	    - 看图 **(i) bit 7**：你可以非常清楚地看到人的轮廓、背景的结构。这是因为 Bit 7 代表数值 $128$ ($2^7$)，它决定了像素是偏黑还是偏白，包含了图像的主要**结构信息**。
        
		- **最低有效位 (LSB, Bit 0) 主要是噪声**:
		    看图 **(b) bit 0**：看起来像老式电视的雪花点（随机噪声）。这是因为 Bit 0 代表数值 $1$ ($2^0$)，它反映的是光照或传感器产生的微小波动，对人眼识别图像内容几乎没有帮助。
            
	    -  应用_: 这一点在图像隐写术或压缩中很有用。
        ![[Pasted image 20260205010113.png]]看图 **(f) bit 4**：在这个特定的图像中，第 4 位平面似乎很好地捕捉到了场景中的光照渐变和中间色调细节。这说明中间的位通常包含纹理和灰度渐变信息。
        对于图(i),这个位平面拆分的二进制层是bit7 ，数学上的“贡献值”：是的，只有 0 或 128

		在 8 位二进制表示中，第 7 位（最高位 MSB）的**权重**是 $2^7 = 128$。

		对于任何一个像素，第 7 位要么是 `0`，要么是 `1`。

	- 如果该位是 `0`，它对原像素总数值的贡献是 $0 \times 128 = 0$。
	- 如果该位是 `1`，它对原像素总数值的贡献是 $1 \times 128 = 128$。
    

	所以在**重建原始图像**的公式里，图 (i) 中每个点确实只代表数值 **0 或 128**。这也解释了为什么它能决定像素的大致亮度（大于等于 128 的像素这一位都是 1，小于 128 的这一位都是 0）。
	
	 1. 视觉上的“显示值”：通常是 0 和 255
	
	如果你直接把一个只包含 0 和 128 的矩阵显示出来，128 只是中等灰度（灰色），那么图 (i) 看起来应该是“黑色背景上的灰色轮廓”。
	
	但在课件展示的图 (i) 中，我们可以看到黑白对比非常强烈（甚至比原图更黑白分明）。这是因为为了**方便人眼观察**，在生成这种位平面图时，通常会进行**二值化缩放**处理：
	
	- **0** 仍然显示为 **黑色 (0)**。
	    
	- **1 (或 128)** 被映射为 **白色 (255)**。

#### B. 采样与分辨率 (Sampling & Resolution) ☝️ **(Finger String 重点)**

- **核心权衡 (Trade-off)**:
    
    - **低分辨率 (Low resolution)**: 丢失细节信息，但存储空间小。
        
    - **高分辨率 (High resolution)**: 保留细节，但存储需求大。
        
- **问题**: 对于一张内容简单的图（如白板上的几个字）和一张复杂的风景图，如何选择最合适的 $N \times N$ 大小？。
    
- **答案**: 这引出了**采样定理 (Sampling Theorem)** 和**频率**的概念。我们需要找到一个能保留信息且占用空间最小的表示法。
    

#### C. 傅里叶变换 (Fourier Transform) —— 进入频率域

这是本节课的核心难点。老师引入了一个关键思想：**任何周期函数都可以表示为不同频率的正弦和余弦波的叠加** [Slide 9, cite: 3555]。

1. **直观理解频率**:
    
    - **空间域 (Spatial Domain)**: 也就是我们平时看的图像矩阵。
        
    - **频率 (Frequency)**: 事件在单位时间内（或单位空间距离内）发生的次数 。
        
    - _图像中的频率_: 图像中亮度变化剧烈的地方（如斑马纹、边缘）代表**高频**；变化平缓的地方（如天空、平滑背景）代表**低频** 。
        
2. **一维信号的傅里叶变换** [Slide 10-11]:
    
    - **变换公式 (FT)**: $Fp(\omega)=\int_{-\infty}^{\infty}p(t)e^{-j\omega t}dt$。将信号从时间域 $t$ 转换到频率域 $\omega$ 。
        
    - **逆变换公式 (Inverse FT)**: 将信号从频率域还原回时间域 。
        
    - _助教提示_: 再次强调，老师说**不需要背这个积分公式**，只需知道它可以实现两个域之间的转换 。
        
3. **幅度与相位 (Magnitude & Phase)** [Slide 16-19]:
    
    - 傅里叶变换的结果是复数，包含**实部 (Re)** 和**虚部 (Im)**。
        
    - **幅度 (Magnitude)**: $|Fp(\omega)|$，表示某个频率成分的强度（能量）。
    - **计算**：复数的模长，即 $\sqrt{\text{实部}^2 + \text{虚部}^2}$
        
    - **相位 (Phase)**: $arg(Fp(\omega))$，表示波的位置/偏移。
    - **计算**：复数的辐角，即 $\tan^{-1}(\frac{\text{虚部}}{\text{实部}})$（见图底部右侧公式）。
        
    - **关键实验 (The Eye/Ear Experiment)** [Slide 19]:
        
        - 如果你取“眼睛”图片的相位 + “耳朵”图片的幅度进行重建，结果看起来像**眼睛**！
            
        - **结论**: **相位 (Phase) 包含了图像最重要的结构信息**，而幅度主要影响整体的明暗模式 
    - **频率分布的概念 (Low vs High Frequency)**：
		
		老师利用幅度图（图 a）解释了频率分布。他指出：
		
		- 当 $\omega$ 很小（接近 0）时，是**低频信息** (Low frequency information)。
		    
		- 当 $\omega$ 很大（远离中心）时，是**高频信息** (High frequency information)。 这为后面讲“低频代表轮廓，高频代表细节/噪声”做了铺垫 。
            
4. **为什么要用傅里叶变换？** [Slide 20]:
    
    - **压缩 (Compression)**: 许多图像只包含少量的高频信息。如果我们丢弃这部分（例如只保留5%的系数），依然能重建出清晰的图像，从而实现压缩 。
        
    - **去噪 (Denoising)**: 噪声通常表现为高频分量，在频率域中滤除高频可以去噪 。
        
    - **加速计算**: 在频率域做卷积（Convolution）比在空间域快得多 。
        

#### D. 其他变换 (Other Transforms) [Slide 22-23]

- 除了傅里叶变换，还有离散余弦变换 (DCT, 用于JPEG)、小波变换 (Wavelets, 用于JPEG2000)。
    
- 小波变换 (Wavelet) 在处理局部特征时比傅里叶变换更有效。

### 🧠 4. 术语与公式速查 (Terminology & Formulas)

|**术语 (Term)**|**解释 (Explanation)**|**备注/应用**|
|---|---|---|
|**Spatial Domain (空间域)**|图像的原始像素表示，坐标为 $(x, y)$。|我们平时看到的图像。|
|**Frequency Domain (频率域)**|图像的频率表示，坐标为 $(u, v)$ 或 $\omega$。|傅里叶变换后的结果。|
|**MSB (Most Significant Bit)**|最高有效位（第7位），权重为 $2^7=128$。|包含图像的主要视觉结构。|
|**Fourier Transform (FT)**|将信号分解为正弦波和余弦波的数学工具。|$e^{-j\omega t} = \cos(\omega t) - j\sin(\omega t)$|
|**Phase (相位)**|波的起始位置/偏移。|决定了图像中物体的位置和轮廓。|
|**Sampling Theorem (采样定理)**|为了不失真地恢复信号，采样频率必须至少是信号最高频率的两倍（奈奎斯特频率）。|决定图像分辨率选择的理论基础。|

### ✍️ 5. 复习与思考题 (Practice Questions)

1. **[概念题]** 在 Slide 19 的实验中，为什么使用 "Ear" 的幅度和 "Eye" 的相位重建出来的图像看起来像 "Eye"？
    
    - _Answer:_ 因为在图像信号中，相位谱 (Phase Spectrum) 携带了大部分关于几何结构和边缘位置的信息，而幅度谱 (Magnitude Spectrum) 主要包含各频率成分的强弱（如整体对比度、纹理粗细）。因此相位决定了“是什么物体”。
        
2. **[应用题]** 如果我想对图像进行有损压缩，在频率域中应该丢弃哪些数据？为什么？
    
    - _Answer:_ 通常丢弃**高频分量**（High-frequency components）。因为高频对应图像的快速变化细节（或噪声），人眼对高频细节的敏感度低于低频轮廓，丢弃它们对视觉质量影响较小。
        
3. **[实战题]** 为什么在处理图像之前，建议将 `uint8` (0-255) 转换为 `float`？
    
    - _Answer:_ `uint8` 是整数，进行数学运算（如傅里叶变换、归一化、除法）时会发生截断误差（如 $5/2=2$），导致精度丢失或溢出。转换为 `float` 可以保证计算精度。
