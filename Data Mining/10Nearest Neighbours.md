这是一份为你整理的 **COMP6237 Data Mining: Nearest Neighbours (K-NN)** 课程完整梳理与学习指南。

> **💡 课程摘要与重点总览** 本节课系统讲解了 K-近邻（K-Nearest Neighbours, K-NN）算法在分类和回归任务中的应用。K-NN 是一种无需显式训练的“懒惰学习（Lazy Learning）”算法，其核心思想是通过计算数据点之间的距离，利用最相似的 $K$ 个邻居来进行投票（分类）或加权平均（回归）。课程重点探讨了 $K$ 值的选择权衡、不同距离加权方案（反比、减法、高斯），并深入剖析了 K-NN 在实际应用中面临的挑战：异构数据尺度差异、维度灾难（Curse of Dimensionality）以及海量数据下的计算瓶颈。针对这些问题，老师重点提出了 Z-score 标准化、随机投影（Johnson-Lindenstrauss 引理）以及局部敏感哈希（LSH）等前沿工程解决方案。

### 📖 按章节详细讲解

#### 1. 问题引入与 K-NN 核心机制 (Slides 2-6 / @0:42 - 12:10)

- **直观场景**：通过电影推荐系统（如预测用户是否喜欢电影《Joker》）或糕点分类（巧克力蛋糕 vs. 菠萝挞）引入概念。
    
- **懒惰学习（Lazy Learning）**：K-NN 不像其他算法那样预先训练模型参数，而是直接存储所有训练数据，直到需要预测时才计算距离。这意味着它“零训练成本”但“预测成本高”。
    
- **分类 vs. 回归**：
    
    - **分类**：在特征空间中找到未知点的 $K$ 个最近邻，基于**多数表决（Majority Vote）**分配类别。
        
    - **回归**：找到 $K$ 个最近邻后，对其目标值进行**加权平均（Weighted Average）**以预测连续值。
        

#### 2. K 值的选择与影响 (Slides 7-12 / @16:02 - 23:49)

- **$K$ 值的影响**：
    
    - $K$ 太小（如 $K=1$）：预测结果会非常不稳定（Jumpy），容易受到噪声数据点的严重影响。
        
    - $K$ 太大：邻域可能包含来自其他类别的点，导致预测结果过于平滑（Over-smoothed），模糊了类别边界。
        
- **如何选择最优 $K$**：老师建议在实践中使用**留一法交叉验证（Leave-one-out Cross-Validation）**。即从训练集中每次剔除一个数据点作为测试点，使用剩余点进行 K-NN 预测，计算不同 $K$ 值下的平均误差，选择误差最小的 $K$。对于二分类问题，$K$ 应选择奇数以避免平票。
    

#### 3. 加权 K-NN (Weighted K-NN) (Slides 13-16 / @23:55 - 29:29)

- 传统的多数表决对 $K$ 个邻居一视同仁。为了让距离更近的邻居拥有更大的决策影响力，我们需要将“距离（Distance）”转化为“权重/相似度（Similarity）”。
    
- **三种加权方案**：
    
    - **反比加权（Inverse Weighting）**：$w=\frac{1}{dist+c}$ （加入常数 $c$ 避免分母为零）。
        
    - **减法加权（Subtraction Weighting）**：$w=\max(0, c-dist)$ （避免出现负权重）。
        
    - **高斯加权（Gaussian Weighting）**：$w=\exp(-\frac{dist^2}{c^2})$ （衰减平滑，适用于大多数场景）。
        

#### 4. K-NN 的痛点与解决方案 (Slides 17-25 / @29:34 - 47:17)

- **异构数据（Heterogenous Data）**：如果特征的尺度不同（例如身高1.5-1.8m，收入10K-1M），数值范围大的特征会主导距离计算。**解法**：使用 Z-score 标准化对特征进行缩放。
    
- **维度灾难（Curse of Dimensionality）**：在高维空间中，所有数据点之间的距离趋于一致，寻找“最近”邻居失去意义。**解法**：降维技术（如 PCA）。但在**极端高维**下，PCA 可能会扭曲点间距离。老师在此引入了 **Johnson-Lindenstrauss 引理**，建议使用简单的**随机投影（Random Projection）**来近似保留距离。
    
- **海量数据计算瓶颈**：每次预测都要与所有存储点计算距离，时间复杂度极高。**解法**：局部敏感哈希（LSH, Locality Sensitive Hashing）或树形结构（如 K-D Trees）。LSH 通过随机超平面将空间划分为多个桶，预测时只需与同一桶内的数据进行比较，大幅降低复杂度。

# 10. Feature Scaling（特征缩放）为什么极其重要？

## 10.1 距离会被大尺度特征支配

讲义中给出一个非常典型的尺度问题：

```
height: 1.5m 到 1.8mweight: 30kg 到 100kgincome: $10K 到 $1M
```

如果直接用欧氏距离，income 的数值范围远大于 height 和 weight，于是距离几乎完全由 income 决定。讲义因此提示使用 Z-score 等方法进行标准化。

## 10.2 为什么这是 k-NN 的大问题？

k-NN 的预测完全依赖距离。如果某个特征尺度很大，它就会主导距离计算。

例如：

```
Person A:height = 1.70weight = 65income = 10000Person B:height = 1.71weight = 66income = 900000
```

欧氏距离中 income 差异巨大：

```
income difference = 890000
```

于是 height 和 weight 的差异几乎可以忽略。

这会导致：

```
模型实际上只根据 income 找邻居，而不是综合所有特征。
```

## 10.3 Z-score Standardization（Z-score 标准化）

公式：

```
z = (x - μ) / σ
```

其中：

- μ 是该特征的均值；
- σ 是该特征的标准差。

标准化后：

```
每个特征大致变成均值 0、标准差 1。
```

这使不同特征在距离计算中处于更公平的尺度。

## 10.4 Min-Max Scaling（最小-最大缩放）

公式：

```
x_scaled = (x - min(x)) / (max(x) - min(x))
```

把特征缩放到：

```
[0, 1]
```

适合需要固定范围的模型或特征。
### 🔤 专有名词与核心公式解释

- **Lazy Algorithm (懒惰算法)**：
    
    - **定义**：在训练阶段只存储数据而不构建泛化模型的算法。
        
    - **特点**：训练时间 $O(1)$，测试时间 $O(N \times D)$（N为样本量，D为维度）。
        
- **Z-score Normalization (标准化)**：
    
    - **公式**：$Z = \frac{X - \mu}{\sigma}$。
        
    - **直观解释**：将不同量纲的数据统一到均值为0、标准差为1的分布中，防止某一数值极大的特征主导距离计算。
        
- **Johnson-Lindenstrauss Lemma**：
    
    - **概念**：一种数学引理，证明高维空间中的点可以通过随机矩阵投影到低维空间，同时以高概率极好地近似保留各点之间的欧氏距离。
        
- **LSH (Locality Sensitive Hashing, 局部敏感哈希)**：
    
    - **机制**：使用 $k$ 个随机超平面划分空间，将空间分为 $2^k$ 个区域（桶），每个点获得一个二进制编码（如101）。测试点只与编码相同的点计算距离，将搜索复杂度降至约 $O(d \log n)$。

# 18. Locality Sensitive Hashing（LSH，局部敏感哈希）

## 18.1 LSH 的核心目标

**LSH（Locality Sensitive Hashing，局部敏感哈希）** 是一种 approximate nearest neighbour search（近似最近邻搜索）方法。

目标不是保证找到绝对最近的点，而是：

```
以很高概率快速找到足够近的点。
```

课堂中说，LSH 是一种著名的 hashing method，核心是把 similar points glue into the same bucket。

## 18.2 图书馆类比

课堂中用图书馆类比：

```
如果要找相似书，不必搜索整个图书馆。先把书按粗略类别放到不同书架。搜索时只看相关书架。
```

LSH 的思想类似：

```
1. 先把点 hash 到不同 bucket；2. 相似点更可能进入同一个 bucket；3. 查询时只在同一个或相近 bucket 中搜索；4. 避免扫描整个数据集。
```

## 18.3 超平面切分的直观解释

课堂中提到可以用几条线/切分来编码点的位置：

```
每条切分线把空间分成两边：    一边编码为 0    另一边编码为 1
```

如果有 3 条切分线，每个点可以得到 3-bit code：

```
010111101...
```

相同 code 的点进入同一个 bucket。

课堂转写中说明：用三条 cut 可以把空间划分成多个区域；测试点到来时，只与同一区域中的训练点比较，而不必和全数据集比较。

## 18.4 LSH 的随机性与重复

LSH 通常是随机算法。

课堂中提到，对于随机算法，如果一次不幸运，可以重复多次；重复 100 次可能提高获得好结果的概率。

这对应 LSH 中常见做法：

```
使用多个 hash tables使用多组随机投影扩大候选集合提高 recall
```

## 18.5 LSH 的 trade-off

LSH 的本质权衡：

```
更快速度  vs  更准确最近邻
```

如果 bucket 很小：

```
速度快，但可能漏掉真正近邻。
```

如果 bucket 很大：

```
更准确，但搜索成本上升。
```
# kNN的优势和劣势
## 14.1 优点 Advantages

### 1. 简单易懂

k-NN 的逻辑几乎可以一句话解释：

```
看离我最近的 k 个样本，它们多数是什么，我就预测什么。
```

### 2. 无需训练

没有复杂的参数学习过程。

### 3. 非参数模型 Non-parametric Model

k-NN 不假设数据服从某种固定分布。

这与 Naive Bayes 不同。课堂中对比说，Naive Bayes 有很强的 independence assumption，而 k-NN 没有这种假设。

### 4. 可用于分类和回归

同一个思想可以处理：

```
classification -> majority voteregression     -> average / weighted averagerecommendation -> similar items/users
```

### 5. 决策边界灵活

k 小时可以拟合复杂边界。

---

## 14.2 缺点 Disadvantages

### 1. 预测慢

每次预测都要和大量训练样本比较。

### 2. 内存开销大

必须保存训练数据。

### 3. 对特征尺度敏感

未标准化的特征会支配距离。

### 4. 对无关特征敏感

如果很多特征与标签无关，距离会被噪声污染。

### 5. 高维空间中效果变差

这就是 **curse of dimensionality（维度灾难）**。

### 6. 类别不平衡时容易偏向大类

如果某个类别样本很多，邻域中更可能出现该类。

解决方式包括：

```
1. class weighting2. distance weighting3. resampling4. 更合理的 evaluation metrics
```
