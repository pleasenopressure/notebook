### 📚 1. 课程核心摘要 (Executive Summary)

本节课的核心目标是解决**高维数据**处理难的问题。通过**PCA（主成分分析）**，我们将数据投影到方差最大（Variability highest）的方向上，从而在降低维度的同时保留数据的主要特征（即“最重要的结构”）。

- **数学基础**：理解方差、协方差及其矩阵形式，这是衡量数据“变化”和“相关性”的基石。
    
- **两大工具**：
    
    1. **EVD (特征值分解)**：适用于对称矩阵（如协方差矩阵），直接求出主轴（特征向量）。
        
    2. **SVD (奇异值分解)**：适用于任意矩阵，数值稳定性更好，计算速度更快（截断SVD），是工业界首选。
        
- **关键步骤**：无论用哪种方法，**去均值（Mean Centering）** 是绝对不可省略的第一步。

### 📖 2. 详细内容梳理 (Detailed Walkthrough)

#### 2.1 问题引入：为什么要降维？

- **背景**：数据挖掘中，我们希望用更少的维度代表数据，同时保留“重要结构” 。
    
- **直观例子（长颈鹿数据）**：
    
    - 假设有长颈鹿的身高和体重数据 。如果直接取平均值，会丢失个体差异；如果只保留“身高”（Feature Selection），可能会忽略那些“个子矮但很重”的特例 
    - **目标**：找到一个新的方向（轴），使得数据在这个方向上分布最广（方差最大）。这个方向就是**第一主轴 (First Principal Axis)** [cite: 202, 535]。
        

#### 2.2 数学基石：期望、方差与协方差

为了找到这个“最大方差方向”，我们需要数学工具：

- **期望 (Expectation, $E[X]$)**：即均值，数据的中心位置 。
    
- **方差 (Variance)**：衡量数据偏离均值的程度（Spread）。公式：$\sigma^2 = \frac{1}{n}\sum (x_i - \mu)^2$ 。
    
- **协方差 (Covariance)**：衡量两个变量（如身高和体重）是如何**一起变化**的（描述的是线性相关性）。
    
    - 公式：$\sigma(x,y) = \frac{1}{n}\sum (x-\mu_x)(y-\mu_y)$ 。
        
    - 如果是正值，说明两者正相关（同增同减）；如果是0，说明不相关 。
        
- **协方差矩阵 (Covariance Matrix)**：
    
    - 对于 $n$ 维数据，这是一个 $n \times n$ 的**对称矩阵** 。
        
    - **对角线**是各维度的方差，**非对角线**是协方差 。
        
    - _助教提示_：理解这个矩阵是对角对称的非常重要，因为这决定了我们可以对它使用 EVD。
        

#### 2.3 核心算法 I：基于 EVD 的 PCA

这是 PCA 的经典解法，利用了线性代数中的基（Basis Set）和特征值概念 。

- **原理**：如果 $A$ 是协方差矩阵，那么它的**特征向量 (Eigenvectors)** 就是数据的主轴（Principal Axes）；**特征值 (Eigenvalues)** 的大小对应数据在该轴上的方差大小 。
    
- **算法步骤 (Algorithm 1)**:
    
    1. **去均值 (Mean Centering)**：$Z = X - \mu$，将数据中心移到原点 。
        
    2. **计算协方差**：计算 $Z^T Z$ (成比例于协方差矩阵) 。
        
    3. **特征值分解 (EVD)**：对 $Z^T Z$ 进行分解，得到特征值和特征向量。
        
    4. **排序与选择**：选出最大的 $k$ 个特征值对应的特征向量。
        
    5. **投影 (Project)**：$X_P = ZP$，将数据映射到这 $k$ 个方向构成的低维空间 。
        

#### 2.4 核心算法 II：基于 SVD 的 PCA

这是更通用的解法，也是实际编程（如 scikit-learn）中常用的方法。

- **SVD 定义**：任意矩阵 $A$ 都可以分解为 $A = U \Sigma V^T$ 。
    
    - $U, V$ 是正交矩阵，$\Sigma$ 是对角矩阵（奇异值）。
        
    - 如果 $A$ 是去均值后的数据矩阵 $Z$，那么 $V$ 的列就是协方差矩阵的特征向量（即主成分）。
        
- **算法步骤 (Algorithm 2)**:
    
    1. **去均值**：$Z = \text{MeanCenter}(X)$。
        
    2. **SVD分解**：直接对 $Z$ 做 SVD，得到 $U, \Sigma, V$ 。
        
    3. **提取主成分**：取 $V$ 的前 $k$ 列。
        
    4. **投影**：$X_P = ZP$（其中 $P$ 来自 $V$ 的部分列）。
        

#### 2.5 为什么要用 SVD？(EVD vs. SVD)

老师特别强调了 SVD 的优势 ：

1. **数值稳定性 (Numerical Stability)**：
    
    - 例子：**Läuchli 矩阵**。如果矩阵包含非常小的数 $\epsilon$，计算 $X^T X$ 会导致 $\epsilon^2$，在计算机浮点数表示中可能直接变成 0，导致信息丢失 。
        
    - SVD 直接作用于 $X$，不需要计算平方，保留了精度。
        
2. **通用性**：SVD 不需要矩阵是对称的（虽然协方差矩阵是对称的，但 SVD 流程更通用）。
    
3. **速度**：截断 SVD (Truncated SVD) 可以只计算前 $k$ 个奇异值，速度极快 。
    
SVD 之所以被称为线性代数的“巅峰之作”，就是因为它对**任意**矩阵（无论是方的、扁的、长的，还是满秩、亏秩的）都成立。

这个结论的数学保障来自一个核心定理：**谱定理 (Spectral Theorem)**，特别是针对**对称矩阵**的谱定理。

让我们分步拆解这个逻辑，看看为什么 $U$ 和 $V$ 一定存在且正交，$\Sigma$ 一定是对角矩阵。

##### 1. 核心突破口：构造“对称矩阵”

对于任意矩阵 $A$（维度 $m \times n$），它本身可能很“丑”（不对称、非方阵）。但是，如果我们把它变成下面这两个矩阵，奇迹就发生了：

1. **$A^T A$**：维度是 $n \times n$。
    
2. **$A A^T$**：维度是 $m \times m$。
    

这两个新矩阵有一个极好的性质：它们都是**对称矩阵 (Symmetric Matrices)** 且是 **半正定矩阵 (Positive Semi-definite)**。

##### 2. 利用“谱定理” (The Spectral Theorem)

线性代数中有一条被称为“上帝定理”的规则：**任何实对称矩阵都可以被正交对角化。**

这意味着，对于对称矩阵 $A^T A$：

1. 它一定有 $n$ 个实数特征值，且都非负（$\lambda_i \ge 0$）。
    
2. 它一定有 $n$ 个相互垂直（正交）的特征向量。
    

这正是 SVD 中 $V$ 和 $\Sigma$ 的来源！

##### 第一步：找到 $V$ (右奇异向量)

我们对 $A^T A$ 做特征值分解（EVD）：

$$A^T A = V \Lambda V^T$$

- **$V$**：就是 $A^T A$ 的特征向量组成的矩阵。根据谱定理，$V$ 是**正交矩阵** 。
    
- **$\Lambda$**：是特征值组成的对角矩阵。
    

##### 第二步：找到 $\Sigma$ (奇异值)

因为 $A^T A$ 的特征值 $\lambda_i \ge 0$，我们可以定义**奇异值** $\sigma_i = \sqrt{\lambda_i}$ 。 这就是矩阵 $\Sigma$ 的由来。

##### 3. 最关键的一步：构造 $U$ (左奇异向量)

现在我们有了 $V$ 和 $\Sigma$，甚至不知道 $U$ 是否存在。我们来看看 SVD 的目标公式：

$$A = U \Sigma V^T \implies AV = U \Sigma$$

这意味着，对于每一个 $V$ 中的列向量 $v_i$（即 $A^T A$ 的特征向量），我们需要找到一个 $u_i$，使得：

$$A v_i = \sigma_i u_i$$

**这里是见证奇迹的时刻：**

如果 $\sigma_i \neq 0$，我们可以直接**定义** $u_i$ 为：

$$u_i = \frac{A v_i}{\sigma_i}$$

**问题来了：这样构造出来的 $u_i$ 也是正交的吗？**

答案是肯定的！我们可以验证一下 $u_i$ 和 $u_j$ 的点积（当 $i \neq j$ 时）：

$$u_i^T u_j = \left(\frac{A v_i}{\sigma_i}\right)^T \left(\frac{A v_j}{\sigma_j}\right)$$

$$= \frac{1}{\sigma_i \sigma_j} v_i^T (A^T A) v_j$$

注意 $v_j$ 是 $A^T A$ 的特征向量，所以 $(A^T A) v_j = \lambda_j v_j = \sigma_j^2 v_j$。代入上式：

$$= \frac{1}{\sigma_i \sigma_j} v_i^T (\sigma_j^2 v_j)$$

$$= \frac{\sigma_j}{\sigma_i} (v_i^T v_j)$$

因为我们第一步已经算出 $V$ 是正交矩阵，所以当 $i \neq j$ 时，$v_i^T v_j = 0$。

**结论：** $u_i^T u_j = 0$。这证明了构造出来的 $U$ 也是**正交**的。

##### 4. 总结：SVD 存在的逻辑链

1. **任意矩阵 $A$** $\rightarrow$ 生成对称矩阵 **$A^T A$**。
    
2. **谱定理**保证 $A^T A$ 一定有正交特征向量 $V$ 和非负特征值。
    
3. **定义**奇异值 $\Sigma$ 为特征值的平方根。
    
4. **推导** $U$：通过公式 $u_i = \frac{A v_i}{\sigma_i}$ 构造 $U$。数学推导保证了这样生成的 $U$ 也是正交的。
    
5. 最终得到分解：**$A = U \Sigma V^T$**。
    

这也是为什么课件中提到：

- $U$ (左奇异向量) 实际上是 $A A^T$ 的特征向量 。
    
- $V$ (右奇异向量) 实际上是 $A^T A$ 的特征向量 。
    
- $\Sigma$ 包含的是 $A A^T$ 或 $A^T A$ 特征值的平方根 。
    所以，SVD 并不是魔法，它是建立在“实对称矩阵可以完美对角化”这个坚实数学基础上的必然结果。

### 🔔 3. 教师重点复述 (Teacher's Emphasis)

> **"Mean Centering is an essential step."**
> 
> **“去均值是必不可少的一步。”**

- **出处**：
    
- **助教解读**：在做 PCA 之前，必须把所有数据减去平均值。如果不做这一步，计算出的“主成分”可能会是从原点指向数据中心的向量，而不是数据本身分布的方向，导致降维结果完全错误。务必记住：**PCA 第一步永远是 Normalize/Center data**。
    

> **"Important structure = Correlation/Variance"**
> 
> **“重要结构 = 相关性/方差”**

- **出处**：
    
- **助教解读**：老师反复问“什么是重要结构？”。在 PCA 的语境下，**方差大**意味着信息量大。我们寻找的正是那些能最大程度区分数据点的特征组合（即相关性）。
    

> **"SVD is better... has better numerical stability."**
> 
> **“SVD 更好……具有更好的数值稳定性。”**

- **出处**：
    
- **助教解读**：这是一个典型的考点。虽然 EVD 是理解 PCA 的数学直觉来源，但在工程实现上，我们几乎总是使用 SVD。记得 Läuchli 矩阵的例子，它是用来证明 $X^T X$ 会造成精度丢失的反例。

### 🔧 4. 关键术语与公式速查 (Terminology & Formulas)

| **术语 (CN/EN)**         | **定义/解释**                       | **关键公式**                                |
| ---------------------- | ------------------------------- | --------------------------------------- |
| **方差 (Variance)**      | 数据离散程度的度量。                      | $\sigma^2 = \frac{1}{n}\sum(x_i-\mu)^2$ |
| **协方差 (Covariance)**   | 两个变量协同变化的程度。正值=正相关，0=不相关。       | $Cov(X,Y) = E[(X-\mu_x)(Y-\mu_y)]$      |
| **特征值 (Eigenvalue)**   | 衡量特征向量方向上的变异程度（重要性）。值越大越重要。     | $Av = \lambda v$ ($\lambda$ 是特征值)       |
| **特征向量 (Eigenvector)** | 线性变换后方向不变的向量，PCA中代表主轴方向。        | 同上 ($v$ 是特征向量)                          |
| **EVD**                | 特征值分解，将矩阵分解为特征向量和特征值矩阵。         | $A = Q \Lambda Q^T$ (对称矩阵时)             |
| **SVD**                | 奇异值分解，通用的矩阵分解方法。                | $A = U \Sigma V^T$                      |
| **Truncated SVD**      | 截断 SVD，只保留前 $r$ 个最大的奇异值，用于低秩近似。 | $A \approx U_r \Sigma_r V_r^T$          |

### 📝 5. 复习与思考 (Review & Flashcards)

考试重点 (Based on Learning Outcomes ):

1. **计算题**：给定小规模数据，计算均值、方差和协方差矩阵。
    
2. **概念题**：理解 PCA 的核心思想（最大化方差）、步骤、以及 EVD 和 SVD 的区别。
    
3. **代码实现**：了解如何调用库或手写简单的 PCA（Coursework 相关）。
    

**自测闪示卡 (Flashcards):**

- **Q1: 为什么在做 PCA 之前要对数据进行“去均值” (Mean Centering)?**
    
    - _A1:_ 为了让数据的中心位于原点，保证计算出的协方差矩阵（或 $Z^T Z$）真正反映数据内部的变异方向，而不是反映数据相对于原点的偏移 。
        
- **Q2: 协方差矩阵对角线上的元素代表什么？非对角线元素代表什么？**
    
    - _A2:_ 对角线代表各维度自身的**方差**；非对角线代表不同维度间的**协方差** 。
        
- **Q3: 在 PCA 中，如何决定保留多少个主成分？**
    
    - _A3:_ 通常根据特征值（Eigenvalues）的大小。特征值越大，该方向包含的信息（方差）越多。我们通常选择前 $k$ 个最大的特征值 。
        
- **Q4: 相比于计算 $Z^T Z$ 的 EVD，直接对 $Z$ 做 SVD 有什么好处？**
    
    - _A4:_ SVD 数值稳定性更好（避免了计算 $Z^T Z$ 时小数值平方导致的精度丢失），且 Truncated SVD 速度通常更快 。
