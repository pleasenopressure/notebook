## 1. 基础框架与函数分类

### 1.1 核心定义

- **场景**: 一组智能体（$Ag=\{1...n\}$）需要对一组结果（$\Omega=\{\omega_1...\}$）达成一致 1111。
    
- **偏好 (Preference)**: $\omega \succ_i \omega'$ 表示智能体 $i$ 认为 $\omega$ 优于 $\omega'$ 2。
    

### 1.2 关键区分：SWF 与 SCF

这是考试中容易混淆的概念，请务必根据输出形式进行区分 3：

| **类型**   | **Social Welfare Function (SWF)**                               | **Social Choice Function (SCF)**                                      |     |
| -------- | --------------------------------------------------------------- | --------------------------------------------------------------------- | --- |
| **定义**   | 将个人偏好聚合成**社会偏好排序**                                              | 将个人偏好聚合成**单个社会结果**                                                    |     |
| **输出**   | **Ranking** (排序，如 $A \succ B \succ C$)                          | **Winner** (赢家，如 $A$)                                                 |     |
| **包含算法** | ✅ **Copeland** (科普兰法)<br><br>  <br><br>✅ **Borda Count** (波达计数) | ✅ **Plurality** (多数制)<br><br>  <br><br>✅ **Condorcet Winner** (孔多塞赢家) |     |

## 2. 投票机制与详细计算演示

### 2.1 多数制 (Plurality)

- **规则**: 只看第一志愿，票多者胜 4。
    
- **缺陷**: 容易忽略多数人的次优选择（如课件中 Milk 赢了，但大多数人把它排最后）5。
    

### 2.2 孔多塞 (Condorcet)

- **定义**: 在**两两对决 (Pair-wise)** 中击败所有其他对手的候选人 6。
    
- **孔多塞标准**: 如果存在孔多塞赢家，投票机制必须选他。
    
- **孔多塞悖论 (难点)**:
    
    - **现象**: 群体偏好出现循环（$A \succ B \succ C \succ A$）。
        
    - **逻辑解释 (你的提问)**: 为什么“无论选谁，都有 2/3 的人不满”？
        
        - 假设选 A：B 和 C 都更喜欢 C（因为 $C \succ A$），这占了 2/3。
            
        - 假设选 B：A 和 C 都更喜欢 A（因为 $A \succ B$），这占了 2/3。
            
        - 假设选 C：A 和 B 都更喜欢 B（因为 $B \succ C$），这占了 2/3。
            
        - **结论**: 没有稳定的赢家 7。
            

### 2.3 科普兰法 (Copeland Method) —— 计算演示

- **规则**: $Score = (\text{胜场数}) - (\text{负场数})$。它是孔多塞一致的 8。
    
- **习题课案例演示** (50人投票，6种菜系: T, J, I, M, B, A) 9999：
    
    第一步：构建两两对决矩阵
    
    以 Thai (T) 为例：
    
    - T vs J: T 赢 (得1分)
        
    - T vs I: T 赢 (得1分)
        
    - ... T 赢了所有 5 个对手。
        
    
    **第二步：计算得分 (Score)**
    
    - **Thai (T)**: 5 胜 0 负 $\rightarrow Score = 5 - 0 = \mathbf{5}$
        
    - **Japanese (J)**: 4 胜 1 负 (输给T) $\rightarrow Score = 4 - 1 = \mathbf{3}$
        
    - **Italian (I)**: 3 胜 2 负 (输给T, J) $\rightarrow Score = 3 - 2 = \mathbf{1}$
        
    - **Mexican (M)**: 2 胜 3 负 $\rightarrow Score = 2 - 3 = \mathbf{-1}$
        
    - **British (B)**: 1 胜 4 负 $\rightarrow Score = 1 - 4 = \mathbf{-3}$
        
    - **American (A)**: 0 胜 5 负 $\rightarrow Score = 0 - 5 = \mathbf{-5}$
        
    
    第三步：排序
    
    结果：$T \succ J \succ I \succ M \succ B \succ A$。注意所有分数之和为 0 ($5+3+1-1-3-5 = 0$)，这是验算的好方法 10。
    

### 2.4 波达计数法 (Borda Count) —— 计算演示

- **规则**: $N$ 个候选项，第 1 名得 $N$ 分... 第 $N$ 名得 1 分。总分最高者胜 11。
    
- **习题课案例演示** (6种菜系，最高分6分，最低分1分) 12：
    
    - 投票分布回顾：
        
        - 10人: $I \succ T \succ J \dots$
            
        - 5人: $B \succ A \succ M \dots$
            
        - 8人: $T \succ J \succ M \dots$
            
        - 12人: $J \succ T \succ I \dots$
            
        - 9人: $M \succ J \succ T \dots$
            
        - 6人: $A \succ B \succ I \dots$
            
    
    **计算 Italian (I) 的得分**:
    
    - 10人把它排第1 (6分): $10 \times 6 = 60$
        
    - 5人把它排第6 (1分): $5 \times 1 = 5$
        
    - 8人把它排第4 (3分): $8 \times 3 = 24$
        
    - 12人把它排第3 (4分): $12 \times 4 = 48$
        
    - 9人把它排第4 (3分): $9 \times 3 = 27$
        
    - 6人把它排第3 (4分): $6 \times 4 = 24$
        
    - **总分 (I)** = $60+5+24+48+27+24 = \mathbf{188}$
        
    
    **计算 Thai (T) 的得分**:
    
    - (按同样逻辑计算各位置得票) $\rightarrow$ **总分 (T) = 221**
        
    
    **结论**: $T (221) > J (213) > I (188) \dots$

## 3. 理想属性与单调性详解

### 3.1 核心属性定义

1. **帕累托效率 (Pareto)**: 全员认为 $A > B$，则结果必须 $A > B$ 。
    
2. **无关选项独立性 (Independence of Irrelevant Alternatives (IIA))**: A 和 B 的排名不受 C 的影响 。
    
3. **非独裁 (Nondictatorship)**: 结果不由某一个人独断 。
    
4. **单调性 (Monotonicity)**:
    
    - **定义**: 如果赢家获得的选票支持**增加**（排名上升），他必须依然是赢家 。
        
    - **判定方法 (你的提问)**:
        
        - 看图判断：在课件的练习图中，选项 3 展示了选民将赢家 $b$ 的排名从第 3 提到了第 2，或从第 2 提到了第 1。这就是“支持度增加”，此时 $b$ 必须仍获胜。
            


**弱帕累托效率 (Weak Pareto Efficiency)** 是社会选择理论中用来衡量投票机制是否合理的一个基本属性。
通俗解释 —— “全员反对即淘汰”
根据课件定义 ，它的核心含义是：**“如果所有人都觉得某个选项比另一个好，那么那个较差的选项绝不应该赢。”**
### 3.2 多数制 (Plurality) 违反单调性的反例 (你的提问)

这是一个经典的**“帮倒忙”**现象。

- **初始情况 (A 赢)**:
    
    - 3人: $A \succ B \succ C$ (A: 3票)
        
    - 2人: $B \succ C \succ A$ (B: 2票)
        
    - 2人: $C \succ B \succ A$ (C: 2票)
        
    - **A 获胜**。
        
- **变化 (增加对 A 的支持)**:
    
    - 最后那 2 个投 C 的人决定改投 A 的次优选项 B，或者假设他们想把 A 提上来，导致选票流向改变（具体反例通常设计为 C 的选民为了不让 A 赢而投 B，或者 C 的选民转投 A 导致 B 获胜）。
        
    - 课件反例逻辑 17:
        
        - 原 C 支持者 ($C \succ B \succ A$) 觉得 C 赢不了，决定把 $C$ 移到底部，变成 $B \succ A \succ C$（注意：这里他们实际上把 B 提到了第一，虽然相对于 C 来说 A 的地位也升了，但关键是 B 拿到了这两票）。
            
        - **新结果**: B (4票) > A (3票) > C (0票)。**B 赢了**。
            
    - **解释**: 原本 C 的存在分流了选票，当你试图改变偏好（即使你的初衷不是帮 B），导致 C 退出竞争，B 吸收了 C 的票源从而击败了 A。这就是多数制的不稳定性。

### 🔑 第一层：送分题（所有机制都满足的）

先把大脑负担减半。在正常的民主投票机制讨论中，以下两个属性默认都是**满足（YES）**的：

1. **Nondictatorial (非独裁)**：
    
    - **记忆逻辑**：如果一个机制是独裁的，我们根本不会在课上讨论它。我们讨论的所有机制（多数制、Borda、Copeland）都是民主的。
        
    - **结论**：全部 ✅。
        
2. **Pareto Efficiency / Weak Pareto (帕累托效率)**：
    
    - **记忆逻辑**：这代表“最低限度的理性”。如果大家都觉得 A 比 B 好，结果选了 B，这机制就是坏的。
        
    - **结论**：全部 ✅。
        
    - _注：对于 SCF（如 Plurality）是 Weak Pareto；对于 SWF（如 Borda/Copeland）是 Pareto。_
        

---

### 🔑 第二层：阿罗的诅咒（SWF 机制的死穴）

**针对对象**：**Borda Count** 和 **Copeland**（这两个都是输出排名的 Social Welfare Functions）。

- **记忆核心**：**Arrow's Theorem (阿罗不可能定理)**。
    
- **逻辑链条**：
    
    1. 阿罗定理说：在 $N > 2$ 时，同时满足 **Pareto** + **IIA** + **非独裁** 是不可能的。
        
    2. 我们已经知道 Borda 和 Copeland 都满足 **Pareto** 和 **非独裁**（送分题）。
        
    3. **推论**：所以，它们**必须**牺牲掉 **IIA (无关选项独立性)**。
        
- **结论**：
    
    - **Borda Count**: IIA ❌
        
    - **Copeland**: IIA ❌
        

---

### 🔑 第三层：多数制的“反直觉”（SCF 机制的死穴）

**针对对象**：**Plurality**（多数制，输出赢家的 Social Choice Function）。

- **记忆核心**：**Muller-Satterthwaite Theorem** 的具体体现。
    
- **逻辑链条**：
    
    1. 多数制太简单粗暴了，它只看第一名。
        
    2. 当选票分散时，你试图“帮”某个候选人（提高排名），可能会打破某种微妙的平衡（如之前的 AB 例子）。
        
    3. **记忆口诀**：**“帮倒忙”**。给冠军投票反而让冠军输了。
        
- **结论**：
    
    - **Plurality**: Monotonicity (单调性) ❌
        

---

### 🔑 第四层：Borda 与 Copeland 的决战（Condorcet 一致性）

这通常是考试中区分这两个 SWF 的考点。虽然它们都违反 IIA，但它们对“单挑王”的态度不同。

- **Copeland (科普兰)**：
    
    - **机制**：算胜负场次。这本质上就是无数个“单挑”。
        
    - **记忆**：**C**opeland $\rightarrow$ **C**ondorcet。两个 C 开头。
        
    - **结论**：Condorcet Consistent ✅。
        
- **Borda (波达)**：
    
    - **机制**：算总分。
        
    - **反例**：A 单挑赢了所有人，但大家把 A 排第二，B 排第一，结果 B 总分更高。
        
    - **结论**：Condorcet Consistent ❌。

## 5. 策略性投票 (Manipulation)

- **定义**: 投票者通过**谎报偏好**来获得更好的结果 21。
    
- **习题课演示 (Voter 4 的策略)** 22:
    
    - **现状**: Copeland 机制下，T (4分) 赢了，J (2分) 第二。
        
    - **Voter 4 真实想法**: $J \succ T \succ I \dots$ (最爱 J)。
        
    - **困境**: 诚实投票导致 T 赢。
        
    - **策略**: Voter 4 提交假票 $J \succ I \succ M \succ T \dots$ (故意把 T 踩到脚底)。
        
    - **效果**: T 在与 I、M 的对决中原本能赢，现在因为少了这一票可能输掉。T 的 Copeland 分数下降。如果 T 降到 2 分以下，J 就能逆袭获胜。

## 6. 重点速记卡 (Cheat Sheet)

1. **Copeland 怎么算？** 两两 PK，胜场减负场。
    
2. **Borda 怎么算？** 排名越靠前分越高，加总分。
    
3. **IIA 是什么？** 只有阿罗定理 (SWF) 讨论 IIA；Borda 和 Copeland 都不满足 IIA。
    
4. **单调性是什么？** 只有 Muller-Satterthwaite (SCF) 讨论单调性；Plurality 不满足单调性。
    
5. **为什么还要投票？** 虽然理论上有缺陷且可操纵，但**计算**出如何操纵是很难的 (NP-hard)，这保护了系统 23。
