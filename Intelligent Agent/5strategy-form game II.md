#### 1. 课程精炼摘要

本讲（页 1-32, @0:00-51:10）的核心是解决纯策略纳什均衡（PNE）并不总是存在的问题（例如“匹配硬币”博弈）。为此，我们引入了**混合策略 (Mixed Strategy)**，即玩家在不同纯策略上选择的一个概率分布。在混合策略下，玩家的目标不再是最大化单次效用，而是最大化其**期望效用 (Expected Utility, EU)**。

本讲定义了**混合策略纳什均衡 (Mixed Nash Equilibrium, MNE)**，即一个所有玩家的混合策略组合，其中没有任何玩家可以通过单方面改变自己的概率分布来提高其期望效用。纳什定理 1 保证了 MNE **总是**存在的 [transcript @14:42-15:01]。

最后，我们学习了计算 MNE 的两种核心方法（尤其针对 2x2 博弈）：**最优反应法 (Best Response Method)** 和**无差异原则 (Indifference Principle)**。

#### 2. 教师重点复述（关键提醒）

- **为何需要混合策略？** 因为 PNE 不总存在 [transcript @0:24]。混合策略是为保证均衡解的存在性而引入的。
    
- **目标是期望效用 (EU)**：一旦引入概率，理性玩家的目标就是最大化其 EU。
    
- **无差异原则的陷阱**：此方法仅用于寻找**完全混合**的 MNE [transcript @34:37, 37:50]。如果计算出的概率值不在 $[0, 1]$ 区间内（如 $x=5/4$），这不代表计算错误，而是意味着该博弈**没有完全混合的 MNE**。
    
- **最优反应法更通用**：教授在总结时强调，如果你想找到**所有**的纳什均衡（包括纯策略和所有类型的混合策略），画出最优反应函数并找交点是最好的方法 [transcript @49:45-50:51]。

#### 3. 核心术语与定义

- 混合策略 (Mixed Strategy) $\sigma_i$：
    
    玩家 $i$ 在其纯策略集 $S_i$ 上的一个概率分布。
    
- 期望效用 (Expected Utility) $EU_i(\sigma)$：
    
    在所有玩家都使用混合策略 $\sigma$（一个策略组合）时，玩家 $i$ 期望获得的平均效用 2。
    
- $\sigma_{-i}$ (对手策略)：
    
    一个简写符号，代表一个包含了除玩家 $i$ 之外的所有其他玩家的混合策略的组合。例如，在一个 3 人游戏中，$\sigma_{-1} = (\sigma_2, \sigma_3)$。
    
- 混合策略纳什均衡 (Mixed Nash Equilibrium, MNE)：
    
    一个混合策略组合 $(\sigma_1, ..., \sigma_n)$，其中每个玩家的混合策略 $\sigma_i$ 都是对所有其他玩家混合策略 $\sigma_{-i}$ 的最优反应。
    
- 最优反应 (Best Response)：
    
    玩家 $i$ 的策略 $\sigma_i$ 是对 $\sigma_{-i}$ 的最优反应，如果它能最大化玩家 $i$ 的期望效用。即，玩家 $i$ 无法单方面改变策略以获得更高的 $EU$。
    
- 无差异原则 (Indifference Principle)：
    
    在 MNE 中，如果一个玩家 $i$ 以大于 0 的概率混合了多个纯策略（例如 T 和 B），那么在给定对手策略 $\sigma_{-i}$ 的情况下，玩家 $i$ 选择 T 的期望效用必须等于选择 B 的期望效用。

#### 4. MNE 的计算方法详解

##### 方法一：最优反应法 (Best Response Method)

此方法通过画出每个玩家的最优反应函数来找到**所有**纳什均衡（交点）。

1. "最优反应" $EU_{i}(\sigma_{i},\sigma_{-i}) = \max_{\sigma_{i}^{\prime}\in\Sigma_{i}}EU_{i}(\sigma_{i}^{\prime},\sigma_{-i})$ 3 是如何计算的？

我们通过一个例子（讲义第 19 页 4）来计算**玩家 1** 的最优反应 $br_1(y)$：

- **设定变量**：P1 玩 H 的概率为 $x$，P2 玩 H 的概率为 $y$。
    
- 写出 $EU_1(x, y)$：
    
    $EU_1(x, y) = P(H,H) \cdot u_1(H,H) + P(H,T) \cdot u_1(H,T) + P(T,H) \cdot u_1(T,H) + P(T,T) \cdot u_1(T,T)$
    
    $EU_1(x, y) = (x \cdot y) \cdot (2) + (x \cdot (1-y)) \cdot (0) + ((1-x) \cdot y) \cdot (0) + ((1-x) \cdot (1-y)) \cdot (1)$
    
- 化简函数：
    
    $EU_1(x, y) = 2xy + (1-x)(1-y) = 3xy - x - y + 1$
    
- 执行 $\max$ (找到最优的 $x$)：
    
    我们把 $x$ 提出来，得到 $EU_1(x, y) = x(3y - 1) - y + 1$ 5。
    
    这是一个关于 $x$ 的线性函数。为了最大化 $EU_1$，$x$ 的取值取决于其系数 $(3y-1)$ 的符号：
    
    - **若 $y > 1/3$**：系数 $(3y - 1)$ 为正。P1 应取 $x$ 的最大值，即 **$x=1$** 6。
        
    - **若 $y < 1/3$**：系数 $(3y - 1)$ 为负。P1 应取 $x$ 的最小值，即 **$x=0$** 7。
        
    - **若 $y = 1/3$**：系数 $(3y - 1)$ 为零。$EU_1$ 的值与 $x$ 无关，P1 的**任何 $x \in [0, 1]$** 都是最优反应 8。
        

2. 结果：

我们就得到了 P1 的最优反应函数 $br_1(y)$。同理算出 $br_2(x)$，将两个函数画在图上，它们的所有交点（本例中有 (0,0), (1,1) 和 (2/3, 1/3)）就是全部的纳什均衡 9。

##### 方法二：无差异原则 (Indifference Principle)

此方法是寻找**完全混合 MNE** 的捷径。

1. 核心等式 (2x2 博弈)： 10

- $EU_{1}(T,y)=EU_{1}(B,y)$ (P1 对 T 和 B 无差异) 11
    
- $EU_{2}(L,x)=EU_{2}(R,x)$ (P2 对 L 和 R 无差异) 12
    

**2. 关键问题：为什么 $EU_{1}(T,y)=EU_{1}(B,y)$ 这个等式中没有 $x$？**

- **回答：** 因为这个等式的目的，是用来**解出玩家 2 的策略 $y$**。
    
- **逻辑：** 玩家 1（P1）是一个理性玩家。他**只有**在“100% 选 T”的期望收益和“100% 选 B”的期望收益**完全相等**时，才愿意使用混合策略（即 $x$ 在 0 和 1 之间）。
    
- $EU_1(T, y)$ 指的是 P1 **如果 100% 选 T**（此时 $x=1$），面对 P2 的策略 $y$ 时的期望效用。它的计算只依赖 P2 的 $y$ 。
    
- $EU_1(B, y)$ 指的是 P1 **如果 100% 选 B**（此时 $x=0$），面对 P2 的策略 $y$ 时的期望效用。它的计算也只依赖 P2 的 $y$ 。
    
- 因此，我们建立 $EU_{1}(T,y)=EU_{1}(B,y)$ ，就是为了找到那个**能使 P1 感到“无所谓”的 $y$ 值**。
    
- 同理，$EU_2(L, x) = EU_2(R, x)$ 是用来解出 P1 的策略 $x$ 的 。
    

3. 对计算结果 $x=5/4$ 的深层解读 (来自 Slide 30 )

- 计算过程：
    
    $EU_2(L,x) = 1x + 10(1-x) = 10 - 9x$
    
    $EU_2(R,x) = 0x + 5(1-x) = 5 - 5x$
    
    令两者相等：$10 - 9x = 5 - 5x \Rightarrow 5 = 4x \Rightarrow x = 5/4$ 。
    
- 表面信息：
    
    $x=5/4$ 不是一个有效的概率（必须在 $[0, 1]$ 之间）。因此，该博弈没有完全混合的 MNE。
    
- 深层信息 (严格优势策略)：
    
    $x=5/4$ 是这两个 $EU$ 函数唯一的交点，且它在 $x=1$ 的右侧。这意味着在整个有效区间 $x \in [0, 1]$ 内，这两个函数永不相交。
    
    我们来检查一下区间内的优劣：
    
    - 在 $x=0$ 时：$EU_2(L) = 10$，$EU_2(R) = 5$。 ($L > R$)
        
    - 在 $x=1$ 时：$EU_2(L) = 1$，$EU_2(R) = 0$。 ($L > R$)
        
    - **结论：** 无论 P1 采取什么策略 $x$，P2 玩 L 的期望效用**总是**严格高于玩 R。
        
    - 这意味着 **L 是 P2 的严格优势策略**。一个理性的 P2 永远不会玩 R（即 $y=1$）。这就解释了为什么不可能存在 _完全混合_ 的 MNE（因为 $y$ 必须是 1，而不是介于 0 和 1 之间）。

3. **验证一个给定的策略组合是否为 MNE (19:52 - 23:07)**

- **问题：** 检查 $\sigma_1 = (1/3 T, 2/3 B)$ 和 $\sigma_2 = (3/4 L, 1/4 R)$ 是否为 MNE。
    
- **方法：** 使用**冷漠原则 (Indifference Principle)** (20:08)。如果这是一个 MNE，那么每个参与者对于他们以正概率选择的策略，其期望效用必须是相等的（即“冷漠”）。
    
- **步骤：** 我们来检查 Player 2 是否“冷漠” (21:19)。
    
    1. 计算 P2 在 P1 玩 $\sigma_1$ 时，选择 L 的期望效用：
        
        $EU_2(L, \sigma_1) = u_2(T,L)\sigma_1(T) + u_2(B,L)\sigma_1(B)$
        
        $EU_2(L, \sigma_1) = 3(1/3) + 2(2/3) = 1 + 4/3 = 7/3$ (22:08, 讲师的计算是正确的)
        
    2. 计算 P2 在 P1 玩 $\sigma_1$ 时，选择 R 的期望效用：
        
        $EU_2(R, \sigma_1) = u_2(T,R)\sigma_1(T) + u_2(B,R)\sigma_1(B)$
        
        $EU_2(R, \sigma_1) = 4(1/3) + 1(2/3) = 4/3 + 2/3 = 6/3 = 2$ (22:17)
        
    3. **比较：** $7/3 \neq 2$ (22:21)。
        
- **结论：** Player 2 并不“冷漠”！他选择 L (7/3) 严格优于选择 R (2)。因此，$\sigma_2$ 不是对 $\sigma_1$ 的最佳对策。**这个组合不是 MNE**。

#### 5. 复习速查卡

**1. 为什么需要混合策略？**

- 因为纯策略纳什均衡 (PNE) 不总是存在（例如“匹配硬币”）。
    
- 纳什定理 (1951) 保证，混合策略纳什均衡 (MNE) **总是**存在 。
    

**2. 什么是 MNE？**

- 一个策略组合（概率分布），其中每个玩家的混合策略都是对其他人混合策略的**最优反应** 20。
    
- 玩家目标是最大化**期望效用 (EU)** 21。
    

**3. 如何计算 MNE (2x2)？**

- **方法一：最优反应法 (找所有 NE)**
    
    1. 设 P1 概率 $x$, P2 概率 $y$。
        
    2. 计算 $EU_1(x, y)$，并求 P1 的最优反应 $br_1(y)$ 22。
        
    3. 计算 $EU_2(x, y)$，并求 P2 的最优反应 $br_2(x)$ 23。
        
    4. 画出 $br_1$ 和 $br_2$ 的图像，**所有交点** 都是 NE 24242424。
        
- **方法二：无差异原则 (仅找完全混合 NE)**
    
    1. **前提：** 假设存在一个完全混合 MNE（即 $x, y$ 都在 $(0, 1)$ 区间）25。
        
    2. P1 必须对他的纯策略 T 和 B 无差异 [transcript @37:20] $\Rightarrow$ $EU_1(T, y) = EU_1(B, y)$。用此等式**解出 $y$** 26。
        
    3. P2 必须对他的纯策略 L 和 R 无差异 [transcript @37:33] $\Rightarrow$ $EU_2(L, x) = EU_2(R, x)$。用此等式**解出 $x$** 27。
        
    4. **检查：** 如果解出的 $x, y$ 确实都在 $(0, 1)$ 内，则 $(x, y)$ 是一个 MNE。如果不在（例如 $x=5/4$），则该博弈**没有**完全混合的 MNE 28。

**4. “混合均衡” (Mixed) vs “完全混合均衡” (Fully Mixed) 

- **“混合策略纳什均衡” (MNE) 是一个通用术语。** 它**包含**了“纯策略纳什均衡 (PNE)” (12:53)。
    
- PNE 是一种特殊的 MNE，只是其概率 $x$ 或 $y$ 恰好等于 1 或 0 (13:37)。
    
- **“完全混合均衡” (Fully Mixed)** 是 MNE 的一种，它特指所有参与者使用的概率**严格位于 (0, 1) 之间**，_不是_ 0 或 1

**5. “数字”策略型游戏的解题技巧 (38:10 - 41:58)**

- 如果遇到一个游戏，策略不是 {T, B}，而是**数字**（例如，从 [0, 1] 中选一个数 $x$），不要被复杂的效用函数吓倒 (39:18)。
    
- **核心技巧：** 始终只比较两种情况：
    
    1. 当我们选择**相同**的数字时会发生什么 (e.g., $x=y$) (39:58)？
        
    2. 当我们选择**不同**的数字时会发生什么 (e.g., $x \neq y$) (40:16)？
        
- 通过比较这两种情况下的效用，你就能判断参与者是想“匹配”对方 (match)，还是想“远离”对方 (as far as possible)，从而找到均衡。

**6. 一个游戏完全可以有多个混合策略纳什均衡 (MNE)**
在**$2 \times 2$**游戏中（像我们目前在课件和练习中主要处理的），你通常只会找到**一个**完全混合策略纳什均衡（Completely Mixed Nash Equilibrium）。

但是，对于**$3 \times 3$ 或更大**的更复杂游戏，**是的，完全有可能存在多个完全混合策略纳什均衡**。

 **为什么 $2 \times 2$ 游戏通常只有一个？**

这和我们寻找均衡的方法——**冷漠原则 (Indifference Principle)** 1——直接相关。

在一个 $2 \times 2$ 游戏中，我们寻找一个完全混合均衡 $((\sigma_1(T)=x, \sigma_1(B)=1-x), (\sigma_2(L)=y, \sigma_2(R)=1-y))$，其中 $x$ 和 $y$ 都在 $(0, 1)$ 区间内。

我们建立的方程是：

1. **Player 1 必须“冷漠”**： $EU_1(T, y) = EU_1(B, y)$ 2222。
    
    - 这个方程是关于 $y$ 的一个**线性方程**。除非在极特殊的“退化”(degenerate) 情况下（比如 $T$ 和 $B$ 的收益对 $y$ 的变化完全一样），这个方程会解出一个**唯一**的 $y$ 值 。
        
2. **Player 2 必须“冷漠”**： $EU_2(L, x) = EU_2(R, x)$ 4444。
    
    - 同样，这是关于 $x$ 的一个**线性方程**，它会解出一个**唯一**的 $x$ 值 。
        

因为我们分别解出了**唯一的 $x$** 和 **唯一的 $y$**，所以我们最多只能找到**一个** $(x, y)$ 组合，也就是一个完全混合策略纳什均衡。

 **为什么更大的游戏可以有多个**？

当我们从 $2 \times 2$ 扩展到 $3 \times 3$ 或 $m \times n$ 游戏时，数学变得复杂得多。

- **对于 $3 \times 3$ 游戏：**
    
    - Player 1 要在策略 A, B, C 之间“冷漠”。
        
    - Player 2 也要在策略 L, M, R 之间“冷漠”。
        
- **求解的方程：** 这不再是两个简单的一元一次方程，而是一个**非线性的方程组**。
    
    - 例如，Player 1 的冷漠条件是 $EU_1(A, \sigma_2) = EU_1(B, \sigma_2) = EU_1(C, \sigma_2)$。
        
    - Player 2 的冷漠条件是 $EU_2(L, \sigma_1) = EU_2(M, \sigma_1) = EU_2(R, \sigma_1)$。
        
- **多个解：** 这种复杂的方程组（特别是多项式方程组）在数学上**完全有可能**有多个不同的解。每一个解（其中所有概率都在 $(0, 1)$ 之间）都对应一个**独立的、完全混合的纳什均衡**。
