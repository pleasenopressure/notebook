### 课程笔记：合作博弈 (Cooperative Games)

本讲座从非合作博弈转向合作博弈，重点研究玩家如何通过结盟、达成协议来共同创造和分配价值。

#### 1. 合作博弈与联盟博弈 (Cooperative vs. Coalitional Games)

- **非合作博弈：** 玩家独立决策，追求个人利益最大化（如纳什均衡）。
    
- **合作博弈：** 玩家可以组成联盟 (Coalitions)，达成有约束力的协议，共同协调行动以获取更大利益。
    
- **联盟博弈 (Coalitional Games)：** 是合作博弈的一种核心模型，假设联盟产生的总价值（效用）可以在成员间**自由转移**（Transferable Utility, TU）。
    

#### 2. 联盟博弈的正式定义

一个联盟博弈由一个二元组 `(N, v)` 定义：

1. **N：** 一个有限的**玩家集合** (Set of Players)。例如 `N = {1, 2, 3}`。
    
2. **v：** 一个**联盟价值函数 (Coalitional Function)**。它将**每个**可能的联盟 `S` (即 `N` 的任意一个子集) 映射到一个实数 `v(S)`，表示该联盟 `S` 独立合作所能创造的总价值。
    
    - **联盟 (Coalition)：** `N` 的任意子集 `S ⊆ N`。
        
    - **大联盟 (Grand Coalition)：** 包含所有玩家的联盟，即 `N` 本身。
        
    - **约束：** 空联盟的价值为零，`v(∅) = 0`。
        

#### 3. 联盟博弈的类型

- **超可加博弈 (Superadditive Games)：** 合作总是有益的。对于任何不相交的联盟 `S` 和 `T`，`v(S ∪ T) ≥ v(S) + v(T)`。联盟越大，价值至少不会减少。
    
    - _示例：_ 企业家（发明家、咨询师、销售员）合作、冰淇淋购买博弈。
        
- **简单博弈 (Simple Games)：** 联盟的价值只能是 0（失败）或 1（获胜）。
    
    - _示例：_ 联合国安理会投票。
        
- **加权多数博弈 (Weighted Majority Games)：** 简单博弈的特例。每个玩家 `i` 有一个权重 `wᵢ`，存在一个配额 `q`。联盟 `S` 获胜当且仅当 `∑_{i∈S} wᵢ ≥ q`。
    
    - _示例：_ 议会组阁 `[q; w₁, w₂, ..., wₙ]`。
        

#### 4. 博弈结果与理想分配 (Outcomes & Imputations)

一个联盟博弈的结果 (Outcome) 由两部分组成：

1. **联盟结构 (Coalition Structure, CS)：** 玩家集合 `N` 的一个**划分**，描述了玩家最终如何分组（例如 `{{1,2}, {3}}`）。
    
2. **收益向量 (Payoff Vector, x)：** 一个向量 `x = (x₁, x₂, ..., xₙ)`，`xᵢ` 是玩家 `i` 获得的收益。
    

为了使分配 `x` 合理，我们通常要求它至少满足两个基本条件：

- **1. 效率性 (The Efficiency Property)**
    
    - **定义：** 所有玩家分配到的收益总和，必须**恰好等于**大联盟（所有玩家共同合作）所能创造的总价值 `v(N)`。
        
    - **公式：** `∑_{i∈N} xᵢ = v(N)`
        
    - **含义：** 这个公理确保了合作所产生的所有价值都被**完整分配**，既没有被浪费，也没有凭空产生额外的收益。
        
- **2. 个体理性 (Individual Rationality)**
    
    - **定义：** 每个玩家的收益 `xᵢ` 必须至少等于该玩家单独行动所能获得的价值 `v({i})`。
        
    - **公式：** `∀ i ∈ N, xᵢ ≥ v({i})`
        
    - **含义：** 任何理性玩家都不会接受一个比自己单干时更差的分配。
        

同时满足“效率性”和“个体理性”的收益向量 `x` 被称为一个**分配 (Imputation)**。

#### 5. 核心 (The Core)：寻求“稳定”的分配

核心 (Core) 是一个衡量**稳定性**的解概念。它不仅要求分配是“合理”的（即 Imputation），还要求它是“稳固”的，不会被任何小团体推翻。

- **核心的定义：** 核心是所有满足“非偏离性”的分配 (Imputation) 的集合。
    
- **深入解释：非偏离性 (No Deviation / Blocking Coalition)**
    
    - **定义：** 对于**所有**可能的联盟 `S ⊆ N`，该联盟的成员在当前分配 `x` 下的总收益 `x(S)`（即 `∑_{i∈S} xᵢ`）必须**至少等于**该联盟 `S` 能够独立创造的价值 `v(S)`。
        
    - **公式：** `∀ S ⊆ N, x(S) ≥ v(S)`
        
    - **含义：** 核心中的分配是稳定的，因为**没有任何一个联盟 `S` 有动机“偏离”**。
        
    - **为什么稳定？** 假设存在某个联盟 `S`，使得 `x(S) < v(S)`。这意味着该联盟 `S` 的成员会发现，他们当前分配到的总收益 `x(S)`，比他们自己脱离大联盟、单独合作能创造的价值 `v(S)` 还要少。因此，他们有充分的动机**阻碍 (Block)** 当前的分配 `x`，并自行组队，因为他们可以通过重新分配 `v(S)` 使得联盟 `S` 中的每个成员都获得比 `xᵢ` 更多的收益。
        
    - **“非偏离性”** 条件杜绝了所有这种“阻碍联盟”的存在，确保了任何玩家子集都无法通过独立合作获得比当前分配更好的集体结果。
        
- **核心的计算：** 核心是由一系列不等式（个体理性、非偏离性）和等式（效率性）共同定义的。
    
- **核心可能为空 (Empty Core)：** 并非所有博弈都存在稳定的分配。
    
    - _示例：_ 在“三玩家多数博弈”（`v({1,2})=v({1,3})=v({2,3})=1, v(N)=1`）中，`x₁+x₂≥1`, `x₁+x₃≥1`, `x₂+x₃≥1`。三式相加得 `2(x₁+x₂+x₃) ≥ 3`，即 `2(1) ≥ 3`，产生矛盾。因此该博弈核心为空。
#### 如何判断一个分配imputation是不是核心
##### 第一步：确认它是一个“分配” (Imputation)

在检查核心之前，必须确认这个方案满足分配的基本要求：

1. **效率性 (Efficiency)**：所有人的钱加起来必须正好等于大联盟的总价值。
    
    - 公式：$\sum_{i \in N} x_i = v(N)$
        
2. **个体理性 (Individual Rationality)**：分给每个人的钱不能少于他自己一个人单干能赚到的钱。
    
    - 公式：对所有 $i$，满足 $x_i \geq v(\{i\})$
        

---

##### 第二步：检查“联盟稳定性” (Stability for all Coalitions)

这是判断核心的关键逻辑。对于所有可能的**子联盟 (Sub-coalitions)** $S \subset N$，分配方案 $x$ 必须满足：

- **核心条件**：联盟成员分到的总和，必须大于或等于该联盟自行能创造的价值。
    
- **公式**：
    
    $$\sum_{i \in S} x_i \geq v(S)$$
    

**直观理解**：如果 $\sum_{i \in S} x_i < v(S)$，那么这个小团体 $S$ 就会产生“反叛”动机，脱离大联盟去自行分配 $v(S)$，因为那样每个人都能分得更多。

**判断分配向量 $(100, 200, 260)$ 是否在核心内？**

2. **检查个体理性**：

    - **结论**：$100 < 170$，即 O 分到的钱比他自己干还要少。

3. **子联盟稳定性**（关键点）：

##### 💡 助教速记卡：核心判断准则

- **加和测试**：全员加和必须等于 $v(N)$。
    
- **下限测试**：每个人的钱 $\geq v(自己)$。

#### 计算core/stable outcome
这道题的核心任务是寻找一个 **稳定结果 (Stable Outcome)**，也就是博弈论中所谓的 **“核” (The Core)**。

解题思路主要分为三个步骤：**理解游戏设定**、**建立约束条件**、**求解不等式组**。下面我为你详细拆解其中的逻辑。

##### 1. 理解游戏设定 (Game Definition)

首先，我们需要看懂题目定义的 **特征函数 (Characteristic Function)** $v(x)$：

- **玩家集合 (Players):** $N = \{1, 2, 3\}$
    
- **联盟价值 (Coalition Values):**
    
    - $v(\{1, 2\}) = 1$
        
    - $v(\{1, 3\}) = 1$
        
    - $v(\{1, 2, 3\}) = 1$
        
    - $v(\text{其他}) = 0$
        

**直观理解 (Intuition):**

- 在这个游戏中，只有包含玩家 1 的联盟才可能产生价值（获得收益 1）。
    
- 玩家 2 和 玩家 3 自己组队（$\{2, 3\}$）或者单干，收益都是 0。
    
- 这就意味着 **玩家 1 (Player 1)** 是一个**关键玩家 (Veto Player)**，没有他，任何收益都无法产生。而玩家 2 和玩家 3 则是互相竞争的“配角”，因为玩家 1 只需要带上他们中的任意一个就能拿到满额收益 1。
    

##### 2. 建立约束条件 (Formulating Constraints)

要找到基于 **大联盟 (Grand Coalition)** $\{1, 2, 3\}$ 的稳定结果，我们需要分配总收益（这里是 1）。假设分配给玩家 1, 2, 3 的收益分别为 $x, y, z$。

一个分配方案要成为 **稳定结果 (Stable Outcome)** 或属于 **核 (The Core)**，必须满足以下三个理性条件：

1. **个体理性 (Individual Rationality):** 没人会接受比单干还差的结果。
    
    - $x \ge v(\{1\}) = 0$
        
    - $y \ge v(\{2\}) = 0$
        
    - $z \ge v(\{3\}) = 0$
        
2. **群体理性/效率性 (Group Rationality / Efficiency):** 大家分完所有的蛋糕，不浪费。
    
    - $x + y + z = v(\{1, 2, 3\}) = 1$
        
3. **联盟理性 (Coalitional Rationality):** **这是最关键的一步。** 任何一个小团体（子联盟）分到的总收益，不能少于他们如果不带其他人玩、自己单干能拿到的收益。如果给少了，这个小团体就会背叛大联盟，自己去单干。
    
    - $x + y \ge v(\{1, 2\}) = 1$ （如果不满足，1和2就会踢掉3，自己分1）
        
    - $x + z \ge v(\{1, 3\}) = 1$ （如果不满足，1和3就会踢掉2，自己分1）
        
    - $y + z \ge v(\{2, 3\}) = 0$ （这个条件 $y, z \ge 0$ 已经天然满足）
        

##### 3. 数学推导 (Mathematical Derivation)

图片中的 `Proof` 部分展示了如何通过这些不等式求解出唯一的 $x, y, z$。

**推导逻辑如下：**

1. 利用关键不等式：
    
    我们有两个很强的约束：
    
    $$x + y \ge 1$$
    
    $$x + z \ge 1$$
    
2. 相加 (Summation):
    
    将上面两个不等式相加：
    
    $$(x + y) + (x + z) \ge 1 + 1$$
    
    $$2x + y + z \ge 2$$
    
3. 引入总和约束：
    
    我们要凑出 $x + y + z$ 这一项，因为我们知道它的值是 1。将上式变形：
    
    $$x + (x + y + z) \ge 2$$
    
4. 代入求值 (Substitution):
    
    已知 $x + y + z = 1$（因为总蛋糕只有 1），代入上式：
    
    $$x + 1 \ge 2$$
    
    $$\Rightarrow x \ge 1$$
    
5. **得出结论 (Conclusion):**
    
    - 既然 $x \ge 1$，而且总收益 $x + y + z = 1$，且 $y, z \ge 0$（收益不能为负）。
        
    - 那么 $x$ 只能等于 1。
        
    - 进而 $y$ 和 $z$ 只能等于 0。
        

##### 总结与经济学解释

- **数学结果:** 唯一的稳定解是 $(\{1, 2, 3\}, (1, 0, 0))$。这意味着玩家 1 拿走所有收益，玩家 2 和 3 分文未得。
    
- **博弈论直觉:** 为什么玩家 1 如此霸道？因为玩家 2 和 3 是完全可替代的 (Perfect Substitutes)。
#### 6. 沙普利值 (Shapley Value)：寻求“公平”的分配

沙普利值 (`φᵢ(v)`) 是一种**唯一的**、基于“公平贡献”的收益分配方案。它不关心稳定性，而是计算每个玩家在合作中应得的份额。

- **核心思想：** 一个玩家的公平收益，等于他在**所有可能的加入联盟的顺序（排列）**中，为联盟带来的**平均边际贡献 (Average Marginal Contribution)**。
    
- **计算过程：**
    
    1. 列出所有 `n!` 种玩家加入联盟的排列 `π`。
        
    2. 对于每种排列 `π` 和每个玩家 `i`，找出 `i` 的“前辈”联盟 `Pᵢ(π)`（即在 `π` 中排在 `i` 之前的玩家）。
        
    3. 计算 `i` 在该排列中的边际贡献：`MCᵢ(π) = v(Pᵢ(π) ∪ {i}) - v(Pᵢ(π))`。
        
    4. 玩家 `i` 的沙普利值 `φᵢ(v)` 是所有 `n!` 个 `MCᵢ(π)` 的平均值。
        
- 沙普利值的公理 (唯一性来源)：
    
    沙普利值是唯一满足以下四个公理的分配方案：
    
    1. **效率性 (Efficiency)：** `∑_{i∈N} φᵢ(v) = v(N)`。所有分配的总和等于大联盟价值。
        
    2. **虚拟玩家 (Dummy Player)：** 如果玩家 `i` 对任何联盟都没有贡献（`v(S∪{i}) = v(S)`），则 `φᵢ(v) = 0`。
        
    3. **对称性 (Symmetry)：** 如果玩家 `i` 和 `j` 的贡献完全相同（可互换），则 `φᵢ(v) = φⱼ(v)`。
        
    4. **可加性 (Additivity)：**
        
        - **定义：** 假设有两个独立的博弈 `v₁` 和 `v₂` 同时进行，形成一个复合博弈 `v = v₁ + v₂`（即 `v(S) = v₁(S) + v₂(S)`）。
            
        - **公理：** 玩家在复合博弈中的沙普利值，等于其在两个独立博弈中沙普利值的和。
            
        - **公式：** `φᵢ(v₁ + v₂) = φᵢ(v₁) + φᵢ(v₂)`
            
        - **含义：** 这个公理使得我们可以将复杂博弈**分解**为简单的博弈，分别计算沙普利值后再相加，极大地简化了计算。它也符合直觉：你在两个独立项目中应得的报酬总和，等于你分别在每个项目中应得的报酬之和。
            

#### 7. 邦扎夫指数 (Banzhaf Index)：另一种“权力”度量

邦扎夫指数 (`βᵢ(v)`) 是另一种衡量玩家贡献或权力的指标，它不关心玩家加入的**顺序**，只关心玩家加入联盟的**组合**。

- **核心思想：** 一个玩家的权力，等于他在**所有可能的“对手”联盟**中，能够**扭转局势（成为关键玩家）**的平均贡献。
    
- **深入解释：邦扎夫指数的计算过程**
    
    1. **确定目标玩家 `i`**。
        
    2. **列出所有“对手”联盟 `S`**：即所有**不包含**玩家 `i` 的联盟。共有 `2^(n-1)` 个。
       **计算子集的总数（幂集公式）**
		对于集合中的每一个元素（在这里是每一个剩下的玩家），在组成一个联盟时都有 **2 种选择**：
    
	    1. **加入**该联盟。
        
	    2. **不加入**该联盟。
        
		- 假设剩下的玩家有 $k = n - 1$ 个。
		    
		- 第一个玩家有 2 种选择，第二个玩家有 2 种选择……第 $k$ 个玩家也有 2 种选择。
		    
		- 根据乘法原理，所有可能的组合总数就是：
		    
		    $$2 \times 2 \times \dots \times 2 \text{ ($k$ 次)} = 2^k$$
		    
		- 因为这里 $k = n - 1$，所以所有可能的联盟总数就是 **$2^{n-1}$**。
        
    3. 计算边际贡献 MCᵢ(S)：对于这 2^(n-1) 个联盟中的每一个 S，计算 i 加入它所带来的价值增量：
        
        MCᵢ(S) = v(S ∪ {i}) - v(S)
        
    4. **求和总贡献**：将这 `2^(n-1)` 个边际贡献全部相加。
        
    5. 计算平均值：将总贡献除以联盟总数 2^(n-1)，得到邦扎夫指数 βᵢ(v)。
        
        βᵢ(v) = ( ∑_{S ⊆ N \ {i}} [v(S ∪ {i}) - v(S)] ) / 2^(n-1)
        
- **计算示例：三人投票委员会 (A, B, C)**
    
    - _规则：_ 任何两人联盟即获胜 (价值 1)，单人联盟失败 (价值 0)。
        
    - _计算 `β_A(v)` (Alice)：_
        
        1. 目标：Alice (A)。
            
        2. 对手联盟 `S` (不含 A)：`∅`, `{B}`, `{C}`, `{B, C}` (共 4 个)。
            
        3. 计算边际贡献：
            
            - `S = ∅`：`MC_A(∅) = v({A}) - v(∅) = 0 - 0 = 0`
                
            - `S = {B}`：`MC_A({B}) = v({A,B}) - v({B}) = 1 - 0 = 1` (Alice 在此是关键的！)
                
            - `S = {C}`：`MC_A({C}) = v({A,C}) - v({C}) = 1 - 0 = 1` (Alice 在此是关键的！)
                
            - `S = {B,C}`：`MC_A({B,C}) = v({A,B,C}) - v({B,C}) = 1 - 1 = 0` (联盟本身已获胜)
                
        4. 总贡献：`0 + 1 + 1 + 0 = 2`
            
        5. 平均值：`β_A(v) = 2 / 4 = 0.5`
            
    - _同理：_ `β_B(v) = 0.5`, `β_C(v) = 0.5`。
        
- **邦扎夫指数 vs 沙普利值：**
    
    - 邦扎夫指数不满足“效率性”公理（`0.5 + 0.5 + 0.5 = 1.5 ≠ v(N) = 1`）。
        
    - 在简单博弈中，两者都可被视为“权力指数”，衡量玩家成为“关键玩家”(Pivotal Player，即扭转局势者)的概率，但二者对“随机性”的假设不同。
### 1. 什么是关键玩家 (Pivotal Player)？

在简单博弈 (Simple Games) 中，联盟的价值只有两种：**1 (获胜)** 或 **0 (失败)**。

正式定义：

玩家 $i$ 在联盟 $S$ 中是关键的 (Pivotal)，必须满足以下两个条件：

1. 包含玩家 $i$ 的联盟 $S$ 是获胜的：$v(S) = 1$。
    
2. 如果不包含玩家 $i$，该联盟就变为失败的：$v(S \setminus \{i\}) = 0$。
    

直观理解：

玩家 $i$ 拥有一种“一票否决权”或“临门一脚”的力量。在这个特定的团体 $S$ 里，没有你，大家就都输了；有了你，大家才能赢。

---

### 2. 关键玩家在邦扎夫指数中的作用

邦扎夫指数衡量的是一个玩家在**所有可能的联盟组合**中，担任“关键角色”的次数。

**计算逻辑**：

- **Shapley Value** 关注的是玩家加入的**顺序 (Permutations)**。
    
- **Banzhaf Index** 关注的是玩家所属的**组合 (Subsets/Coalitions)**。

## 个人题型总结
这类题目主要有两种类型一种是**加权多数博弈 (Weighted Majority Games)**（每个player有多少成员，最后要满足多少才得到untility）另一种是**超可加博弈**类似于公司合作获得收益（utility是线性增长的）。
前一种可以通过分析所求player在哪些情况下成为了pivotal（utility为1的情况），快速得到答案省的排列组合出来一个个个计算（无论shapley or banzhaf)。
