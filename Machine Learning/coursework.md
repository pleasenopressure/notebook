# 训练集类别不平衡
这是一个非常关键的问题。你在图表中发现的**严重类别不平衡**是这个项目中最大的挑战之一。

如果不解决这个问题，你的模型（尤其是监督模型）几乎肯定会“偷懒”，它会发现只要一直预测占比最高的类别（比如 `7-sitting`），就能获得很高的_总体准确率_ (Overall Accuracy)，但它在识别 `9-stairs` 或 `2-running` 等少数类别时会表现得非常糟糕。

这会导致你的模型**无法满足**课程作业中关于“每个类别”的精确率（Precision）和召回率（Recall）的性能要求 。

以下是解决这个问题的三种主要策略，你可以（也应该）在你的代码中实现它们：

---

### 策略一：算法层面 - 类别加权 (Class Weighting) - **（强烈推荐）**

这是最直接、最推荐的方法，因为它不会改变你的数据，而是通过修改模型的_损失函数_ (Loss Function) 来实现的。

**工作原理：** 你告诉模型：“在训练时，如果你弄错了一个少数类别（如 `9-stairs`），受到的惩罚（loss）要远远大于你弄错一个多数类别（如 `7-sitting`）。”

这迫使模型更加努力地去学习少数类别的模式。

#### 1. 如何在 Random Forest / SVM 中实现 (使用 `sklearn`)

对于你的经典监督模型，`scikit-learn` 让这件事变得非常简单。你只需要在创建分类器时设置一个参数即可：

Python

```
# 在你的 Random Forest Pipeline 中

    ('scaler', StandardScaler()),
    ('rf', RandomForestClassifier(
        random_state=RANDOM_SEED,

    ))
])
```

当你设置 `class_weight='balanced'` 时，`sklearn` 会自动根据 `y_train` 中标签的频率来计算权重，少数类的权重会更高。

#### 2. 如何在 CNN / RNN 中实现 (使用 `tensorflow.keras`)

对于你的深度学习模型，你需要在 `model.fit()` 函数中传递一个手动的权重字典。

你可以使用 `sklearn` 的一个辅助工具来轻松计算这些权重：

### 策略二：数据层面 - 重采样 (Resampling)

这个策略是直接修改你的训练数据集，使其变得“平衡”。**重要提示：** 你应该只对你的**训练数据**（`X_train_windows` 或 `X_train_feat`）进行重采样，_永远不要_对你的测试集（`X_test`）进行重采样。

#### 1. 欠采样 (Undersampling)

- **做法：** 随机从多数类别（`7-sitting`）中删除大量样本，使其数量与少数类别（或所有类别的平均值）相匹配。
    
- **优点：** 训练会变得非常快，因为你的数据集会小得多。
    
- **缺点：** 你丢弃了_大量_可能有用的数据。模型可能会失去学习 `7-sitting` 类别的细微差别的能力。
    

#### 2. 过采样 (Oversampling)

- **做法：** 随机复制少数类别（如 `9-stairs`）的样本，直到它们的数量与多数类别相匹配。
    
- **优点：** 不会丢失任何数据。
    
- **缺点：** 极大地增加了训练集的大小，会使训练变得非常慢。模型可能会对少数类别的特定样本产生_过拟合_（Overfitting）。
    

**如何选择：** 鉴于你的不平衡_非常_严重，简单的随机过采样可能会导致数据集过大，而随机欠采样会丢失太多信息。**我建议优先使用策略一（类别加权）。**

### 1. 训练误差 (Training Error) 和 泛化误差 (Generalisation Error)

这是在 "Pipelines" 部分明确要求你为每个模型测量的。

- **训练误差 (Training error)：** 你的模型在**训练集**上的表现。这表明模型对已知数据的拟合程度。
    
- **泛化误差 (Generalisation error)：** 你的模型在**测试集**（或交叉验证的验证集）上的表现。这是**更重要**的指标，因为它表明模型对**未见过的新数据**的预测能力。
    
- **为什么两者都需要：** 同时报告这两者，可以让你分析**过拟合（Overfitting）**。如果训练误差很低（例如99%准确率），但泛化误差很高（例如60%准确率），这说明你的模型只是“背诵”了训练数据，而没有学会通用的规律。
