## 1. 核心概念：偏差 (Bias) 与方差 (Variance)

这是理解集成学习（尤其是 Bagging）“为什么”有效的基础。

- **目标**：在机器学习中，我们希望我们的**估计器 (estimator) $f^*$**（通过训练数据找到的模型）尽可能接近**真实函数 (true function) $\hat{f}$**（我们想要揭示的潜在规律）。我们的目标是最小化 $f^*$ 和 $\hat{f}$ 之间的距离。
    
- **问题**：在实践中，我们通常有**多个**不同的训练数据集（training datasets）。用同一个算法在这些不同的数据集上训练，会得到多个不同的 $f^*$。这就引出了偏差和方差两个问题。
    

### 专有名词解释

- **偏差 (Bias)**：指的是所有可能的 $f^*$ 的**平均值 $\overline{f}$** 3与**真实函数 $\hat{f}$** 之间的差距 4。
    
    - **高偏差 (High Bias)**：意味着你的模型**系统性地偏离了**真实目标。平均而言，你的所有预测都是错的（即使它们可能彼此很接近）。这通常由**模型过于简单**（欠拟合, Underfitting）引起。
        
- **方差 (Variance)**：指的是不同的 $f^*$（由不同数据集训练得出）**彼此之间的分散程度**。
    
    - **高方差 (High Variance)**：意味着你的模型**对训练数据的微小变化极其敏感**。在数据集 A 上的预测和在数据集 B 上的预测可能天差地别。这通常由**模型过于复杂**（过拟合, Overfitting）引起 5555。

### 老师反复说明解释的内容：高方差与过拟合 (Overfitting)

老师在课堂上 反复强调，**高方差 (High Variance) 就是过拟合 (Overfitting)** 17171717。

- **定义**：过拟合是指你的分类器对**当前的**训练数据表现完美（例如达到 100% 准确率），但它**无法泛化 (generalize)** 到新的、未见过的数据上。
    
- **老师的例子**：如果我根据今天教室里学生的座位训练了一个分类器，它可能 100% 准确。但如果明天两个学生**换了位置**，整个模型就**崩溃了 (broken)**，因为它**过度拟合**了今天这个特定的数据。
    
- **关键洞察**：老师指出，看到 100% 的准确率**不一定是好事**。这通常意味着模型“用力过猛” (overdoing it)，它过度拟合了数据，导致了高方差。你需要保留一定的“不准确性” (inaccuracy) 来为其他可能不同的数据留出空间。

## 2. 核心算法：决策树 (Decision Tree)计算 Gini 不纯度，entropy

决策树是一种非常强大且直观的算法，但它天生具有**高方差 (High Variance)**，是典型的“复杂模型”。[[9Decision Trees]]

- **什么是决策树？**
    
    - 它是一种通过一系列**是/否**问题（分支）来对数据进行分类的模型。
        
    - **优点 (Advantages)**：
        
        1. **可解释性强 (Model Interpretability)**：它是**白盒模型 (White-Box Model)** 18。你可以清楚地向医生解释为什么模型会做出“心脏病发作”的预测（例如：因为血压 > 150 且年龄 > 50）。
            
        2. **数据准备工作少**：不需要数据归一化 (normalization) 或缩放 (scaling)。
            
        3. **易于达到 0 训练误差**：如果树足够深，它可以为每个数据点创建一个叶节点，达到完美拟合。
            
- **如何构建决策树？**
    
    - **核心问题**：树的**分支标准 (Branching criteria)** 是什么？ 19。我怎么知道应该在哪里画线？。
        
    - **老师的例子**：如果我问“你的发色是什么？”来预测心脏病，这是一个**无用的问题**，会导致树变得巨大而无效。但如果我问“你的血压是多少？”，我可能很快就能得到一个有效的分类。
        
    - **目标**：我们希望每一次分支都能产生尽可能**“纯” (Pure)** 的子集，即**不纯度 (Impurity)** 最低。
        
	### 专有名词解释：如何衡量不纯度？
    
    #标签: #机器学习/决策树 #机器学习/评估指标
    
    1. **Gini 不纯度 (Gini Impurity Index)** 20：
        
        - **直观理解**：衡量从一个节点中随机抽取两个样本，它们**类别不同**的概率。
            
        - **公式**：$G_{i}=1-\sum_{k=1}^{n}{p_{i,k}}^{2}$ 。其中 $p_{i,k}$ 是节点 $i$ 中类别 $k$ 实例的比例。
            
        - **“纯”节点**（Gini=0）：如果一个节点 100% 都是同一类别（例如 $p_{blue}=1$），$G = 1 - (1^2) = 0$ 。
            
    2. **熵 (Entropy) / 信息增益 (Information Gain)** 23：
        
        - **直观理解**：源自信息论。熵衡量的是系统的**不确定性 (uncertainty) 或“惊喜度 (surprise)”**。
            
        - **老师的例子**：
            
            - **全白圈 (Pure)** ：熵为 0。我不需要问任何问题 (0 bits) 就能知道下一个是什么。
                
            - **黑白各半 (Mixed)** ：熵为 1 。我需要问 1 个问题（“是黑是白？”）才能确定。
                
            - **四种不同颜色 (Maximal Impurity)** ：熵为 2 。我需要问 2 个问题才能确定是哪一个。
                
        - **公式**：$H_{i}=-\sum_{p_{i,k}\ne0,k = 1}^{n}p_{i,k}log_{2}(p_{i,k})$。
            
        - **目标**：决策树会选择那个能带来**最大信息增益 (Information Gain)**（即不纯度下降最多）的特征进行分裂。
            
- 构建示例：“我该去打网球吗？ (Should I play tennis?)”
    ![[Pasted image 20260120112156.png]]
    这是一个贯穿课程的详细例子。
    
    1. **目标**：我们有 4 个特征（Outlook, Temp., Humidity, Wind），我们想知道哪个特征应该作为**根节点 (root node)**。
        ![[Pasted image 20260120112210.png]]
    2. **计算**：我们分别计算如果用每个特征进行**第一次**分裂，得到的加权 Gini 不纯度是多少。
        
        - Gini(Outlook) = 0.342 
            
        - Gini(Temperature) = 0.439 
            
        - Gini(Humidity) = 0.367 
            
        - Gini(Wind) = 0.428 
            
    3. **决策**：**Outlook** 产生了**最低的 Gini 不纯度 (0.342)** 。
        
    4. **结论**：因此，**Outlook** 成为树的**根节点（第一个分支）**。

## 3. 决策树的问题与解决方案

### 决策树的缺点 (Disadvantages)

1. **高方差 (High Variance) / 过拟合 (Overfitting)**：这是最大的问题。决策树会不惜一切代价完美拟合训练数据，导致泛化能力很差。
    
2. **不稳定性 (Instability)**：
    
    - **老师反复说明解释的内容**：老师在 强调了这一点。PDF 第 30 页 36 显示，将数据集**旋转 (Rotation) 45度**（数据本身没变），会导致决策树构建一个**完全不同且复杂得多**的边界。这证明了它对数据的微小变化极其敏感。
    - ![[Pasted image 20260120112350.png]]
        

### 解决方案 1：正则化 (Regularization)

我们可以通过设置**超参数 (Hyperparameters)** 来“约束” (restrict) 决策树，防止它过度生长。

- **`max_depth`**：限制树的最大深度。
    
- **`min_samples_split`**：一个节点必须有多少样本才允许分裂。
    
- **`min_samples_leaf`**：一个叶节点（leaf node）必须有多少样本。
    
    - PDF 第 31 页 37 的对比图显示，无限制的树 (No restrictions) 严重过拟合，而设置 `min_samples_leaf = 4` 的树产生了更简单、更平滑、泛化能力更强的边界。

## 4. 解决方案 2：集成学习 (Ensemble Learning) 之 Bagging

这是本讲座的最终解决方案。

- **核心思想**：我们已经知道决策树是**高方差、低偏差**的模型（复杂模型）。Bagging 的核心思想是：**通过平均 (average) 多个高方差模型，来显著降低整体的方差** 。
    

### 专有名词解释：Bootstrapping (引导法)

- **定义**：Bagging 的全称是 **Bootstrap Aggregating** 39。
    
- **Bootstrapping** 是一种重采样 (Resampling) 技术 40。
    
- **工作原理**：我们从原始数据集中，**有放回地 (with replacement)** 随机抽取 N' 个样本，来创建一个新的（Bootstrapped）数据集 。
    
- **例子**：如果原始数据是 `[a, b, c, d]`，一个 Bootstrapped 数据集可能是 `[a, b, b, d]` 或 `[c, a, c, a]` 42。
    

### Bagging 的工作流程

#标签: #机器学习/集成学习 #Bagging

Bagging 是一个两阶段过程：

1. **训练阶段 (Training) - 并行** ：
    
    1. 使用 **Bootstrapping** 从原始 N 个样本中，创建出 M 个**不同**的训练集（Set 1, Set 2, ..., Set M） 44。
        
    2. 在**每一个** Bootstrapped 数据集上，独立训练一个**高方差**的分类器（例如，一个完全生长的、未剪枝的决策树）45。
        
    3. 最终，你得到了 M 个**不同**的分类器（Function 1, Function 2, ...） 46。
        
2. **预测/聚合阶段 (Aggregation)**：
    
    1. 当一个新的测试数据 $x$ 到来时，将 $x$ **同时**输入到你训练好的 M 个分类器中 47。
        
    2. 你会得到 M 个**不同**的预测结果（$y_1, y_2, ..., y_M$） 48。
        
    3. **聚合 (Aggregate)** 这些结果 ：
        
        - **分类 (Classification) 问题**：使用**多数投票 (Majority Voting)** 。
            
        - **回归 (Regression) 问题**：使用**平均 (Average)** 。
            

- **心脏病诊断示例** 52：
    
    - 一个测试病人 53 被 3 个不同的决策树诊断。
        
    - **树 1 投票**：Yes (患病) 54。
        
    - **树 2 投票**：No (健康) 55。
        
    - **树 3 投票**：Yes (患病) 56。
        
    - **最终 Bagging 结果**：(Yes, No, Yes) $\rightarrow$ 多数投票为 **Yes** 57。
        

### 随机森林 (Random Forest)

- **定义**：随机森林是 Bagging 的一种特例和改进，它专门使用**决策树**作为基分类器 58。
    
- **双重随机性**：它在 Bagging 的基础上增加了**第二层随机性** 59：
    
    1. **Bootstrapping**：随机采样数据（行随机） 60。
        
    2. **特征随机性 (Features randomness)**：在构建决策树的**每个节点**时，不再是查看**所有**特征（如 Gini 例子中的 4 个），而是只从一个**随机的特征子集**（例如，$\sqrt{n}$ 个特征）中选择最佳分裂点 61。
        
- **目的**：这种额外的随机性确保了每棵树都非常不同，使得树与树之间的**相关性 (Uncorrelatedness)** 更低 ，从而能更有效地降低方差。
    

### Bagging 的优缺点

- **优点 (Advantages)**：
    
    - **显著减少过拟合/降低方差** 。这是它的主要存在理由。
        
    - 可以**并行处理 (Parallel Processing)**，因为每棵树的训练都是独立的 64。
        
    - （通常）能处理缺失值 65。
        
- **缺点 (Disadvantages)**：
    
    - **失去了可解释性 (Low interpretability)** ：你无法再像看单棵决策树一样（白盒）去理解模型的决策逻辑，它变成了一个“黑盒”。
        
    - **不能解决偏差问题 (Doesn't address Bias)** ：Bagging 只能降低方差。如果你的基模型（比如一个过于简单的线性模型）本身就是高偏差的，Bagging 也救不了它。
要选 **正确的 statements**：

✅ **(a) Bagging reduces overfitting**

- Bagging 主要通过 **降低方差** 来让模型更稳定，尤其对决策树这种高方差模型能明显缓解过拟合。
    

❌ **(b) Bagging reduces bias**

- Bagging 主要降的是 **variance**，对 **bias** 通常影响不大（甚至可能略升/不变）。
    

❌ **(c) Random Forest is prone to overfitting**

- Random Forest 通常 **不容易过拟合**（比单棵树稳很多），树很多时更是如此；当然在极端噪声/参数不当时也可能过拟合，但“prone”不对。
    

❌ **(d) Bagging has high interpretability**

- 集成模型（很多个基模型投票/平均）一般 **可解释性较差**，不如单棵决策树。
    

✅ **(e) Boosting reduces bias**

- Boosting 通过逐步纠正前一轮错误，通常能显著降低 **bias**（也可能降低/增加 variance，取决于设置）。
    

✅ **(f) Boosting is highly accurate**

- 在很多任务上（如 AdaBoost、GBDT、XGBoost）往往有很强的预测性能（但也更需要防过拟合）。
    

❌ **(g) Boosting is parallel**

- Boosting 是 **串行/顺序** 训练：后一轮依赖前一轮的结果，所以不天然并行（可做工程优化但本质是 sequential）。
    

✅ **(h) Boosting uses weak learners**

- Boosting 经典设定就是组合很多 **弱学习器**（如决策树桩/浅树）变成强学习器。
